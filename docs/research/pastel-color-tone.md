# 파스텔 색감 조사: 색 있는 바탕과 진한 같은 색 글자

> 지도: [tide-color-tone](../progress/tide-color-tone/map.md)
> 조사일: 2026-11-12

## 0. 왜 조사했나

Tide solid가 너무 쨍하다는 피드백에서 시작했다. 사용자가 마음에 든다고 고른 색감을 분석해, 그 **조합 규칙**만 수치로 정리했다. 2026-11-12에 같은 제품의 여러 기능 화면 이미지 139장을 픽셀 단위로 다시 분석해 범위를 고쳤다. 파스텔 바탕을 찾고 같은 칸 안의 글자·테두리 색을 함께 뽑았다. 외부 제품의 색 값은 이 문서에 옮기지 않는다. 아래 Tide 값은 이 규칙을 Tide 스케일에 대 본 결과다.

수치는 OKLCH(L 밝기, C 채도, H 색상각)와 WCAG 2.x 대비비다.

## 1. 관찰한 조합 규칙

1. **화면 대부분은 무채색이다.** 본문·제목·선택 상태는 잉크색(L 0.28 근처, C 0.015 이하)으로 칠하고, 색은 배지·숫자·아이콘·일정 블록처럼 작은 면적에만 쓴다.
2. **파스텔 바탕은 밝고 색이 은은하게 보인다.** L 0.94~0.97, C 0.02~0.04(노랑 계열 0.025, 초록 계열 0.04). 지금 Tide subtle(50)은 C 0.011이라 회색으로 읽힌다.
3. **파스텔 위 글자는 같은 색상의 아주 진한 색이다.** 파랑·빨강·초록·보라는 L 0.32~0.36, C 0.095~0.118로 색이 살아 있다. 청록 계열은 C 0.05 안팎, 노랑 계열은 L 0.43 안팎으로 덜 진하다. 대비는 8~11:1이다.
4. **바탕보다 한 톤 진한 1px 테두리를 두른다.** L 0.84~0.90, C 0.03~0.04로 바탕보다 채도가 0.01 정도만 높다.
5. **채도를 더 뺀 두 번째 파스텔이 있다.** L 0.94 근처, C 0.015 안팎. 「추천」처럼 덜 중요한 표시에 쓴다.
6. **흰 글자를 얹는 solid는 채도가 낮다.** C 0.12~0.14 수준(파랑 L 0.567 · C 0.142). 면적이 큰 밝은 solid(L 0.69~0.75)는 차트·아이콘 장식이라 흰 글자를 얹지 않는다. 지금 Tide solid(600)는 C 0.10~0.22이고 blue·red가 특히 높다(0.200, 0.222).
7. **계열마다 값을 손으로 맞춘다.** 글자 채도가 계열마다 크게 다르다(초록·빨강 0.11 안팎, 청록 0.05). 공식 하나로 다시 만들면 이 차이가 사라진다.
8. **호버·클릭은 색을 바꾸지 않고 덮는다.** 목록 항목은 잉크색 4%(호버)·8%(포커스), 버튼은 검정 14%(호버)·20%(클릭)를 덮는다. 계열마다 hover 색을 따로 두지 않는다. 그래서 subtle 호버의 밝기 변화(약 0.024)는 지금 Tide(100→200 단계, 약 0.071)보다 훨씬 작다.
9. **링크·선택 글자는 solid와 같은 밝기다.** L 0.57 안팎이라 흰 바탕 대비가 4.5:1에 조금 못 미친다.
10. **보라 파스텔을 많이 쓴다.** 일정·상태 표시에서 파랑 다음으로 자주 나온다.

## 2. Tide 스케일과 비교

| 규칙 | 지금 Tide | 가까운 Tide 단계 | 차이 |
| --- | --- | --- | --- |
| 파스텔 바탕 | subtle 50 (C 0.011) | 100 (L 0.933 · C 0.025~0.031) | 밝기를 0.945 근처로 올리고 채도는 계열마다 맞춰야 함 |
| 파스텔 글자 | text 800 (L 0.45 근처) | 950 (L 0.28 · C 0.053~0.088) | 밝기는 0.33~0.36으로 조금 밝히고, 파랑·빨강은 채도를 올리고 청록은 낮춰야 함 |
| 파스텔 테두리 | 없음(`border`는 light 600, outline용) | 200 (blue C 0.052) | 채도를 낮춘 값이 필요 |
| 두 번째 파스텔 | 없음 | 100과 gray-100 사이 | 새 자리가 필요 |
| solid | 600 (blue C 0.200) | — | 채도를 0.12 안팎으로 낮추면 흰 글자 4.5:1을 지키려고 밝기를 L 0.56 근처로 맞춰야 함 |
| 잉크·회색 | gray-950 `#28292c` (L 0.281) | — | 거의 같음, 바꿀 필요 없음 |

이 규칙으로 정한 Tide 값은 [02 결정](../progress/tide-color-tone/issues/02-grilling-scale-values.md)에 있다.

## 3. Tide와 맞지 않는 점

- **슬롯 구성**: 파스텔 묶음은 바탕·테두리·글자 세 색이다. Tide `text` 슬롯(800)은 배지 밖 강조 글자와 같이 쓰고, `border`(light 600)는 outline용이라 파스텔 테두리와 진한 파스텔 글자를 담을 자리가 없다.
- **두 번째 파스텔**: Tide 강도는 `solid`와 `subtle` 둘뿐이다.
- **앵커와 solid 채도**: 600~800 채도를 낮추면, 바꾸지 않는 500 `#3183f5`(C 0.188)와 600 사이에서 채도가 크게 끊긴다.
- **보라 계열**: 일정 표시처럼 장식용 색이 더 필요할 수 있다. Tide에는 purple 계열이 없다.
- **dark Theme**: 관찰한 화면에 dark 값이 없었다(확인 불가).
