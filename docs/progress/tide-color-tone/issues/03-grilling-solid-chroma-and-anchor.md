# solid 채도와 앵커 결정

Type: grilling
Status: resolved

## Question

기준 solid는 채도가 낮다(C 0.12 안팎, Tide blue-600은 C 0.200). 흰 글자 4.5:1을 지키는 blue 후보는 `#3f77b9`(C 0.119, 4.61:1)다.

정할 것:

- 600~800(solid/hover/active)의 채도를 얼마나 낮출지, 다섯 계열 모두 낮출지
- 바꾸지 않기로 한 앵커 500 `#3183f5`(C 0.188)와의 채도 끊김을 어떻게 처리할지(앵커 유지 + 500~950 점진 감소, 앵커 규칙 완화 등). 앵커 규칙은 tide-v0 지도에서 확정한 사항이라 바꾸면 ADR이 필요하다
- 링크 글자를 solid와 같은 색으로 둘지

근거: [파스텔 색감 조사 §3.2](../../../research/pastel-color-tone.md)

## Answer

- solid 채도 상한은 C 0.13이다. 0.13을 넘는 blue·red·green의 600~800만 낮추고 흰 글자 4.5:1이 되도록 밝기를 맞춘다. amber·cyan은 그대로
- 앵커 blue-500 `#3183f5`는 그대로 둔다. 500은 어느 슬롯도 쓰지 않아 500→600 채도 끊김은 스케일 견본에서만 보인다. 400은 500보다 밝은 쪽이라 이 끊김을 잇지 못한다. 300(파스텔)과 500 사이가 자연스럽도록 채도만 맞춘다
- light `text` 슬롯(단독 색 글자)은 800에서 700으로 바꾼다(처음엔 600으로 정했다가 02 Q29에서 700으로 고침). dark 값은 04에서 정한다
