# 컬러 스케일 후보 시각 비교

Type: prototype
Status: resolved
Blocked by: 02

## Question

`#3183f5`를 앵커로 한 컬러 스케일 후보 2~3개(생성 방식이 서로 다른 것)를 화면에서 비교할 수 있는 임시 페이지를 만든다. 각 후보에서 단계별 흰색/검정 대비, light와 dark Theme에서 어떻게 보이는지, 텍스트와 solid 배경에 쓸 단계 후보를 확인할 수 있어야 한다. 중립색(gray)과 상태색(success, warning, danger, info)의 초안도 포함한다.

## Answer

**생성 방식은 A(OKLCH L 계단 + 앵커 고정)를 쓴다.** gray 초안, 상태색 hue, dark Theme을 "같은 스케일 반전"으로 매핑한 결과도 사람이 보고 문제없다고 판단했다.

### 채택한 생성 규칙 (A)

- 단계: `50, 100, 200, 300, 400, 500, 600, 700, 800, 900, 950` (11단계, Tailwind와 같은 이름)
- 단계별 OKLCH L: Tailwind v4 blue의 L 값을 쓴다. `0.970 / 0.932 / 0.882 / 0.809 / 0.707 / (앵커 0.6215) / 0.546 / 0.488 / 0.424 / 0.379 / 0.282`
- chroma: 계열마다 최대값 × 곡선 `0.06 / 0.13 / 0.24 / 0.43 / 0.67 / 0.87 / 1.0 / 0.99 / 0.81 / 0.60 / 0.37`. sRGB gamut을 벗어나면 chroma만 줄인다.
- **blue 500은 앵커 `#3183f5`(OKLCH L 0.6215, C 0.1882, H 257.8) 원본 hex로 고정한다.** 앵커 L이 Tailwind blue-500 L(0.623)과 거의 같아서 계단에 자연스럽게 들어간다.
- 계열별 hue와 최대 chroma: blue H 257.8 / C 0.2154, gray H 257.8 / C 0.014(blue 기운이 약간 도는 gray), success H 150 / C 0.19, warning H 75 / C 0.19, danger H 27 / C 0.24, info H 225 / C 0.15

### 프로토타입에서 확인한 사실

- blue 단계별 흰색 대비: 1.09 / 1.22 / 1.42 / 1.81 / 2.62 / 3.69 / **5.05** / 6.48 / 8.51 / 10.19 / 14.62
- **blue, success, warning, danger, info 모두 흰 배경에서 4.5:1을 처음 넘는 단계가 600이다.** 텍스트와 흰 글자 solid 배경의 후보는 600이다.
- gray는 600의 흰색 대비가 4.93으로 4.5:1을 넘는다. dark(gray-950 배경)에서 4.5:1을 넘는 가장 진한 단계는 blue 400, gray 400이다.
- A는 대비를 생성 규칙으로 보장하지 않는다(OKLCH L과 WCAG 대비는 선형 관계가 아님). 단계별 대비는 따로 검사해야 한다. B(HCT)와 C(대비 역산)도 600에서 4.5:1을 넘는 결과는 같았고, 차이는 주로 양 끝 단계의 간격과 채도였다.

### 「컬러 Foundation 결정」 티켓으로 넘기는 것

- Semantic 매핑(텍스트/solid = 600 등)을 확정하는 일, dark 전용 스케일을 둘지 판단하는 일, 대비 자동 검사(CI) 여부, Token 원본 값을 OKLCH로 둘지 hex로 둘지는 이 티켓에서 정하지 않았다.
