# Tabs 고른 표시 이동과 모양(shape)

탭을 바꾸면 고른 표시가 이전 탭에서 새 탭으로 미끄러지게 하고, `shape` prop으로 밑줄(`underline`)·둥근 바탕(`box`)을 고르게 한다. 결정은 [ADR 0038](../../decisions/0038-tabs-moving-indicator-and-shape.md).
