# 42: 실제 Windows Contrast Theme 확인

Status: ready-for-human
Blocked by: 35 (고대비 수동 확인과 0.5.0 릴리스)

## What to build

티켓 35에서는 macOS Chrome DevTools의 `forced-colors` 흉내로 확인했다. 이 티켓에서는 실제 Windows Contrast Theme에서 같은 항목을 다시 확인한다. 흉내 모드로는 테마마다 다른 시스템 색(Aquatic, Desert, Dusk, Night sky)과 Windows 브라우저의 처리를 볼 수 없기 때문이다. Windows 기기나 VM을 쓸 수 있을 때 한다.

## 수용 기준

- [ ] Windows 11 Contrast Theme(밝은 것 1개 이상, 어두운 것 1개 이상)에서 Edge나 Chrome으로 문서 사이트 또는 Storybook을 확인한다. 볼 것: raised 표면·오버레이 경계, 포커스 표시(ring/field/highlight), Checkbox·Radio·Switch 상태, 선택 탭, 상태 아이콘.
- [ ] 문제가 있으면 새 티켓을 만들어 고친 뒤 다시 확인한다. 테마 이름, Windows·브라우저 버전, 결과를 Comments에 남긴다.
