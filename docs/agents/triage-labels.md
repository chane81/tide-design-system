# Triage 라벨

스킬들은 다섯 가지 triage 역할로 상태를 표현한다. 이 파일은 각 역할이 이 저장소의 트래커(`docs/progress/` 이슈 파일의 `Status:` 줄)에서 어떤 문자열로 쓰이는지 정리한다.

| mattpocock/skills의 라벨 | 이 트래커의 라벨  | 의미                                               |
| ------------------------ | ----------------- | -------------------------------------------------- |
| `needs-triage`           | `needs-triage`    | 메인테이너가 검토해야 함                           |
| `needs-info`             | `needs-info`      | 작성자에게 추가 정보를 기다리는 중                 |
| `ready-for-agent`        | `ready-for-agent` | 명세가 완성되어 AFK 에이전트가 바로 처리할 수 있음 |
| `ready-for-human`        | `ready-for-human` | 사람이 직접 구현해야 함                            |
| `wontfix`                | `wontfix`         | 처리하지 않음                                      |

스킬이 역할을 언급하면(예: "AFK-ready triage 라벨을 붙여라") 이 표에서 대응하는 문자열을 쓴다.
