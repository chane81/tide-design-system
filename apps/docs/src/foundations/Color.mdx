# 컬러

색은 용도를 나타내는 **Semantic Token**(`bg-primary-solid`)으로 고릅니다.

Semantic Token은 색 자체인 **Primitive Token**(`blue-600`)을 가리킵니다. Theme(light, dark)이 바뀌면 가리키는 Primitive만 바뀌므로, Component와 앱은 Semantic Token을 씁니다.

## 쓰는 법

Role 6개(`neutral`, `primary`, `success`, `warning`, `danger`, `info`)와 강도(`solid`, `subtle`)로 이름을 만듭니다.

- 배경: `bg-<역할>-<solid|subtle>[-hover|-active]`. 예: `bg-primary-solid`, `bg-danger-subtle-hover`
- 글자: `text-<역할>`. 예: `text-success`. neutral은 없습니다.
- 테두리: `border-<역할>`. 예: `border-warning`. neutral은 없습니다.

## 규칙

- 강도는 생략하지 않습니다. `bg-primary`는 없습니다.
- 속성마다 쓸 수 있는 이름만 class로 생깁니다. `text-bg-primary` 같은 class는 없습니다.
- `solid` 배경 위 글자는 모든 Role에서 `text-on-solid`입니다.
- `subtle` 배경 위 글자는 같은 Role의 `text-<역할>`이고, neutral은 `text-default`입니다.
- hover와 active 색도 Token입니다. 예: `hover:bg-primary-solid-hover active:bg-primary-solid-active`

## 공통 Token

- 표면 층: `bg-canvas`(페이지), `bg-surface`(카드, 패널), `bg-raised`(popover, modal)
- 글자: `text-default`, `text-muted`, `text-disabled`, `text-on-solid`
- 테두리: `border-default`(장식용 구분선), `border-strong`(입력창 등 UI 경계), `border-raised`(raised 표면 경계. light는 투명, dark는 gray-800)
- 기타: `bg-disabled`, `bg-overlay`(modal 뒤 막), `outline-focus`(포커스 표시)

## 그 밖의 쓰임

- gradient: 배경 Token 이름을 그대로 씁니다. 예: `from-canvas`, `to-primary-subtle`
- 그림자 색: class 없이 CSS 변수 `--tide-shadow-color`만 있습니다. 그림자 단계는 Elevation에서 다룹니다.
- Tailwind 없이: `@tide-tds/foundation/tokens.css`를 불러와 `--tide-<class 이름>` 변수를 씁니다. 예: `var(--tide-bg-primary-solid)`, Primitive는 `var(--tide-color-blue-600)`

## 색 스케일

계열 6개(`blue`, `gray`, `green`, `amber`, `red`, `cyan`)가 50~950의 11단계이고, 그 밖에 `white`, `black`이 있습니다. `blue-500`이 Tide의 기준색 `#3183f5`입니다.

- 읽는 법: 괄호 안은 그 계열을 쓰는 Role입니다. 단계 아래 L, D는 light canvas(흰색)와 dark canvas(`gray-950`) 위 대비비입니다.
- Primitive class는 브랜드 색처럼 Semantic Token으로 표현할 수 없는 곳에만 씁니다.
- `bg-blue-500`은 Tide 값입니다. `bg-slate-500` 같은 Tailwind 기본 팔레트 class는 없습니다.

## 대비

실제로 함께 쓰는 Token 조합(**대비 쌍**)이 기준을 넘는지 light와 dark 모두 자동으로 검사합니다. 기준은 WCAG 2.x 대비비로, 글자는 4.5:1, UI 경계와 포커스 표시는 3:1 이상입니다.

### 검사에서 뺀 Token

아래 Token은 대비 검사 대상이 아닙니다. 비활성 상태는 색만으로 나타내지 않고, Component가 `disabled`/`aria-disabled` 속성과 cursor로도 표현합니다.
