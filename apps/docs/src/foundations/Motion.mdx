# 움직임

전환 애니메이션의 시간(duration)과 곡선(easing) Token입니다.

움직임은 적게, 자주 쓰는 곳일수록 더 적게 씁니다. 하루에 수백 번 여닫는 UI가 300ms씩 움직이면 사용자는 그만큼 기다립니다.

## duration과 easing

| 종류     | class                    | 쓰는 곳            |
| -------- | ------------------------ | ------------------ |
| duration | `duration-normal`(300ms) | 들어올 때          |
| duration | `duration-fast`(150ms)   | 나갈 때, 상태 변화 |
| easing   | `ease-out`               | 모두               |

재생 버튼을 눌러 비교해 보세요.

<Canvas of={MotionStories.Motion} sourceState="none" />

- 시간을 적지 않은 transition class(`transition-colors`, `transition-opacity` 등)는 기본값 `fast`와 `out`을 씁니다. 버튼처럼 혼자 있는 조작 요소는 `transition-colors` 하나면 됩니다.
- Tailwind의 `ease-in`, `ease-in-out`, 숫자 duration(`duration-200`)은 남아 있어 앱 코드에서 쓸 수 있습니다. Tide Component는 쓰지 않습니다.

```tsx
<button className="bg-primary-solid transition-colors hover:bg-primary-solid-hover">저장</button>
<div className="transition-opacity duration-normal ease-out">…</div>
```

## 무엇을 움직이나

| 구분    | Component                           | 나타날 때                                    | 사라질 때                       |
| ------- | ----------------------------------- | -------------------------------------------- | ------------------------------- |
| 자주 씀 | Menu, Select·Combobox 목록, Tooltip | 바로                                         | opacity `fast`                  |
| 가끔 씀 | Popover, Toast                      | opacity + blur 4px + translate 4px, `normal` | 같은 조합을 절반 세기로, `fast` |
| 가끔 씀 | Dialog류                            | opacity + scale 0.96 → 1, `normal`           | 같은 조합을 약하게, `fast`      |

- 반복되는 목록 항목(Menu 항목, Select 옵션, Table 행)의 hover는 바로 바뀝니다. 혼자 있는 조작 요소는 `transition-colors` `fast`입니다.
- `transition-all`은 쓰지 않습니다. `transition-colors`, `transition-[opacity,translate]`처럼 속성을 적습니다.
- 상태 변화는 CSS transition으로 합니다. keyframe은 Spinner·Skeleton처럼 계속 도는 것에만 씁니다.
- 애니메이션만으로 상태를 알리지 않습니다. 색, 아이콘, 라벨 중 하나가 함께 바뀝니다.

## 움직임 줄이기

움직임 줄이기(`prefers-reduced-motion: reduce`)를 켜면 이동, 확대·축소, blur 대신 opacity 전환만 보여 줍니다. 바로 사라지게 하지는 않습니다.

- 이동·확대·blur는 `motion-safe:`로 감쌉니다. 움직임 줄이기에서는 그 class만 빠지고 opacity 전환(`fast`)이 남습니다.
- 유지하는 것: Spinner 회전, Progress, hover 색 변화, 포커스 표시. Token 값은 바뀌지 않습니다.
- 멈추는 것: Skeleton 깜빡임.

```tsx
<div className="transition-opacity motion-safe:transition-[opacity,translate] motion-safe:duration-normal">
  …
</div>
```

## Theme 전환

Theme을 바꾸는 순간에는 transition을 끕니다. 방법은 [Theme 전환](?path=/docs/시작하기-theme-전환--docs)에 있습니다.

## CSS 변수

Tailwind 없이 쓸 때는 `@tide-tds/foundation/tokens.css`의 변수를 씁니다.

- duration: `--tide-duration-fast`(150ms), `--tide-duration-normal`(300ms)
- easing: `--tide-ease-out`(`cubic-bezier(0, 0, 0.2, 1)`)

```css
.panel {
  transition: opacity var(--tide-duration-normal) var(--tide-ease-out);
}
```

Component에 `className="duration-normal"`을 넘기면 기본 class를 이깁니다(`cn`이 두 duration class를 압니다).
