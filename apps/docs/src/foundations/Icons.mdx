# 아이콘

`@tide-tds/icons`에서 `PlusIcon`처럼 `Icon` 접미사가 붙은 이름으로 import합니다. 쓰지 않는 아이콘은 앱 번들에 들어가지 않습니다. `@tide-tds/desktop`을 설치하면 함께 설치됩니다.

```tsx
import { PlusIcon } from "@tide-tds/icons";

<PlusIcon />;
```

아이콘 이름은 Tide가 정합니다. 키를 지우거나 이름을 바꾸는 것은 breaking change이고, 새 아이콘을 더하는 것은 patch입니다.

### 선 두께

label(굵기 500) 옆에서는 기본값 2px, body(굵기 400) 옆에서는 1.5px를 씁니다. 렌더된 두께 기준이라 크기와 상관없이 같습니다.

### 장식용 아이콘과 이름 있는 아이콘

- 텍스트 옆 아이콘은 장식용입니다. 의미는 텍스트가 전하므로 기본값(숨김)을 그대로 둡니다.
- 아이콘만으로 의미를 전할 때는 `aria-label`을 줍니다.
- 아이콘만 있는 버튼은 아이콘이 아니라 버튼에 이름을 줍니다(IconButton은 `aria-label`이 필수입니다).
- 상태(성공, 경고, 오류)는 색만으로 구분하지 않습니다. 아이콘 모양이나 텍스트로도 구분합니다.
- 한 화면에서 아이콘 세트를 섞지 않습니다. Component의 아이콘 자리에는 다른 라이브러리의 아이콘도 넣을 수 있지만, 같은 화면에서는 한 세트만 씁니다.
