# 아이콘

`@tide-design/icons`에서 `PlusIcon`처럼 `Icon` 접미사가 붙은 이름으로 import하는 SVG 아이콘입니다.

## 쓰는 법

```tsx
import { PlusIcon } from "@tide-design/icons";

<PlusIcon />;
```

- 설치: `@tide-design/icons`를 `@tide-design/components`와 같은 버전으로 직접 설치합니다. components만 설치하면 pnpm에서는 import할 수 없습니다([설치](?path=/docs/시작하기-설치--docs)).
- 번들: 쓰지 않는 아이콘은 앱 번들에 들어가지 않습니다.
- 이름: Tide가 정합니다. 키를 지우거나 이름을 바꾸는 것은 breaking change이고, 새 아이콘을 더하는 것은 patch입니다.
- 색: `currentColor`라서 글자색을 따릅니다. 아이콘이나 부모에 글자색 class를 줍니다.

## Props

| prop          | 기본값 | 설명                                                                                                           |
| ------------- | ------ | -------------------------------------------------------------------------------------------------------------- |
| `size`        | `16`   | 가로·세로 크기(px)                                                                                             |
| `strokeWidth` | `2`    | 화면에 그려지는 선 두께(px). 크기를 바꿔도 두께가 그대로입니다(`vector-effect: non-scaling-stroke`).           |
| `aria-label`  | 없음   | 주면 `role="img"`인 이름 있는 이미지가 됩니다. 없으면 장식용입니다(`aria-hidden="true"`, `focusable="false"`). |
| 나머지        | -      | `className`, `style`, `ref` 등 SVG 속성을 그대로 넘깁니다.                                                     |

## 사용 가이드

### 크기

Component 안에서는 Component의 `size`에 맞춥니다.

| Component size | 텍스트 옆 아이콘 | IconButton 아이콘 |
| -------------- | ---------------- | ----------------- |
| `xs`           | 14px             | 16px              |
| `sm`           | 14px             | 16px              |
| `md`           | 16px             | 20px              |
| `lg`           | 20px             | 24px              |

<Canvas of={IconsStories.Sizes} />

### 선 두께

label(굵기 500) 옆에서는 기본값 2px, body(굵기 400) 옆에서는 1.5px입니다. 렌더된 두께 기준이라 크기와 상관없이 같습니다.

<Canvas of={IconsStories.StrokeWidths} />

### 장식용 아이콘과 이름 있는 아이콘

- 텍스트 옆 아이콘은 장식용입니다. 의미는 텍스트가 전하므로 기본값(숨김)을 그대로 둡니다.
- 아이콘만으로 의미를 전할 때는 `aria-label`을 줍니다.
- 아이콘만 있는 버튼은 아이콘이 아니라 버튼에 이름을 줍니다(IconButton은 `aria-label`이 필수입니다).
- 상태(성공, 경고, 오류)는 색만으로 구분하지 않습니다. 아이콘 모양이나 텍스트로도 구분합니다.
- 한 화면에서는 아이콘 세트 하나만 씁니다. Component의 아이콘 자리에 다른 라이브러리의 아이콘을 넣을 수는 있습니다.
