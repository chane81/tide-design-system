# Link

문장 안에서 다른 페이지나 위치로 이동하는 텍스트 링크입니다.

<Canvas of={LinkStories.Basic} />

## 사용 시점

- 본문, 도움말, 표 안에서 다른 페이지나 같은 페이지의 위치로 갈 때
- 외부 문서로 보낼 때

## 쓰지 않을 때

- 저장, 삭제처럼 동작을 실행하면 Button을 씁니다.
- 이동을 버튼 모양으로 보여야 하면 `render`로 링크를 넘긴 Button을 씁니다.

## 예시

### 색 고르기

`color`로 색 이름(Role, 색 계열, 앱 브랜드 색)을 고릅니다. 기본값은 `primary`입니다. 바깥 요소의 색은 물려받지 않습니다.

<Canvas of={LinkStories.Colors} />

### 문장에 맞추기

글자 크기와 굵기는 주변 텍스트를 따릅니다. 밑줄은 항상 있습니다.

<Canvas of={LinkStories.InheritText} />

### Next Link로 렌더하기

`render`에 Next.js `Link`를 넘기면 클라이언트 이동을 씁니다. 이름이 겹치므로 Next 쪽을 다른 이름으로 import합니다.

```tsx
// app/page.tsx
import { Link } from "@tide-tds/components";
import NextLink from "next/link";

<Link render={<NextLink href="/docs" />}>시작하기</Link>;
```

서버 컴포넌트에서도 바로 씁니다.

<Canvas of={LinkStories.AsNextLink} />

### 새 탭으로 열기

`target="_blank"`를 주면 새 탭으로 열립니다. 새 탭이 열린다는 것을 텍스트로 알립니다.

### Don't: 동작을 링크로 둔다

페이지를 옮기지 않는 동작은 Button으로 둡니다. 키보드 사용자는 링크를 Space로 실행할 수 없습니다.

## 접근성

### 기본 제공

- 역할: `link`. 이름은 텍스트입니다.
- 키보드: Tab으로 포커스하고 Enter로 이동합니다.
- 포커스 표시: 키보드 포커스에 2px ring이 보입니다(`focus-ring`).
- 색: 모든 색 이름의 글자색이 light·dark 표면에서 4.5:1 이상입니다.
- 밑줄: 색만으로 링크를 구분하지 않도록 밑줄이 항상 있습니다. hover에는 두꺼워집니다.
- 고대비 모드(forced-colors): 시스템 링크 색으로 바뀌고 밑줄은 남습니다.

### 앱이 할 일

- 링크 텍스트만 읽어도 어디로 가는지 알 수 있게 씁니다.
- 새 탭으로 열면 텍스트로 알립니다(「WCAG 2.2(새 탭)」).
- 밑줄을 지우지 않습니다(`no-underline`). 지우면 색만으로 링크를 알아봐야 합니다.

## Props

`a`의 props를 모두 받습니다(`color`는 색 이름으로 바뀝니다). `ref`는 루트 요소에 연결되고, `className`은 기본 class 뒤에 붙어 충돌하면 이깁니다. 루트에는 `data-color`가 붙습니다. 비활성 상태는 없습니다. 갈 수 없는 링크는 텍스트로 둡니다.
