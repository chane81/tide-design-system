# Skeleton

내용이 오기 전에 그 자리를 회색 모양으로 표시합니다. 천천히 깜빡이고, 움직임 줄이기를 켠 사용자에게는 멈춰 있습니다. 스크린 리더에는 읽히지 않습니다.

<Canvas of={SkeletonStories.Basic} />

## 사용 시점

- 목록, 카드, 프로필처럼 모양을 미리 아는 내용을 불러올 때
- 내용이 들어와도 레이아웃이 밀리지 않게 자리를 잡아 둘 때

## 쓰지 않을 때

- 모양을 모르거나 버튼 안처럼 작은 자리에서 기다릴 때는 Spinner를 씁니다.
- 얼마나 남았는지 알 수 있는 작업(업로드, 백업)은 Progress를 씁니다.
- 아주 짧게 끝나는 로딩에는 Skeleton을 띄우지 않는 편이 화면이 덜 번쩍입니다.

## 예시

### 모양

| `variant`    | 모양        | 크기                                                 | radius |
| ------------ | ----------- | ---------------------------------------------------- | ------ |
| `text`(기본) | 글 한 줄    | 높이 1em(글자 크기를 따른다), 너비 100%              | `sm`   |
| `rect`       | 사각형 영역 | 너비 100%, 높이는 `className`으로 줍니다(예: `h-24`) | `md`   |
| `circle`     | 원          | `size`로 고릅니다                                    | `full` |

<Canvas of={SkeletonStories.Variants} />

### Avatar 자리

`circle`의 `size`는 Avatar와 같은 24·32·40·48px입니다. 같은 `size`를 주면 Avatar가 들어와도 자리가 바뀌지 않습니다.

| `size`     | 지름 |
| ---------- | ---- |
| `xs`       | 24px |
| `sm`       | 32px |
| `md`(기본) | 40px |
| `lg`       | 48px |

<Canvas of={SkeletonStories.CircleSizes} />

### 글 여러 줄

`text`의 높이는 글자 크기(1em)를 따릅니다. 나중에 올 글의 텍스트 스타일 class(`text-body-md` 등)를 부모나 Skeleton에 주고, 줄마다 너비를 다르게 하면 글처럼 보입니다.

## Do/Don't

### Do: 나중에 올 내용과 같은 모양·크기로 두고, 영역에 `aria-busy`를 붙인다

자리가 같으면 내용이 들어올 때 화면이 밀리지 않습니다. 불러오는 동안 영역에 `aria-busy="true"`를 두고, 다 오면 지웁니다.

<Canvas of={SkeletonStories.DoMatchLayout} />

### Don't: Skeleton만으로 불러오는 중임을 알린다

Skeleton은 스크린 리더에 읽히지 않습니다. 오래 걸리는 로딩이면 보이는 문구나 `role="status"` 문구로 함께 알립니다.

<Canvas of={SkeletonStories.DontOnlySkeleton} />

## 접근성

### 기본 제공

- 숨김: 루트에 `aria-hidden="true"`가 늘 붙어 접근성 트리에 나오지 않습니다.
- 움직임 줄이기: 깜빡임(`pulse`, opacity 1 → 0.5 → 1, 2초)은 `prefers-reduced-motion: reduce`에서 멈추고 모양만 남습니다.
- 대비: 장식용이라 대비 의무가 없습니다. 색은 `bg-neutral-subtle-active`로, dark raised 표면 위에서도 보이게 subtle 3단계 중 가장 진한 값을 씁니다.
- 고대비 모드(forced-colors): 배경은 시스템 배경색이 되고, 평소 투명한 1px 경계가 시스템 글자색으로 그려져 모양이 남습니다.

### 앱이 할 일

- 불러오는 영역에 `aria-busy="true"`를 붙이고, 다 오면 지웁니다.
- 오래 걸리면 보이는 문구나 `role="status"`로 불러오는 중임을 알립니다.
- 내용이 오면 Skeleton을 내용으로 바꿉니다.

## Props

서버 컴포넌트로 쓸 수 있습니다. `div`의 props를 받습니다(`aria-hidden`·`children`은 받지 않습니다). `ref`는 `div`에 연결되고, `className`은 기본 class 뒤에 붙어 충돌하면 이깁니다(예: `w-1/2`, `rounded-none`). `size`는 `variant="circle"`일 때만 받습니다.
