# Pagination

긴 목록을 여러 쪽으로 나눴을 때 쪽 사이를 이동하게 합니다. `Pagination`(`<nav>` + `<ul>`), `PaginationItem`(`<li>`), `PaginationLink`(쪽 번호), `PaginationPrevious`·`PaginationNext`(이전/다음), `PaginationEllipsis`(생략)를 조합합니다. 어떤 번호를 보일지는 앱이 정합니다.

<Canvas of={PaginationStories.Basic} />

## 사용 시점

- 검색 결과·게시글처럼 항목이 많고, 사용자가 특정 쪽으로 돌아가거나 쪽 번호를 공유해야 할 때
- 항목 수가 정해져 있어 전체 쪽 수를 알 때

## 쓰지 않을 때

- 끝없이 이어 읽는 피드는 「더 보기」 Button이나 무한 스크롤을 씁니다.
- 단계를 차례로 진행하는 흐름(가입 1/3단계)은 Pagination이 아닙니다.
- 쪽이 하나뿐이면 Pagination을 보이지 않습니다.

## 예시

### 부분

| Component            | 요소                         | 하는 일                                                                                      |
| -------------------- | ---------------------------- | -------------------------------------------------------------------------------------------- |
| `Pagination`         | `<nav>` 안의 `<ul>`          | 이름 있는 탐색 영역. 기본 이름은 「페이지 이동」입니다. 항목 사이 4px, 좁으면 줄을 바꿉니다. |
| `PaginationItem`     | `<li>`                       | 목록 항목. 기본 class가 없습니다.                                                            |
| `PaginationLink`     | `<a>`(Button ghost, 32px)    | 쪽 번호. `current`면 `aria-current="page"`와 primary subtle 채움입니다.                      |
| `PaginationPrevious` | `<button>`(IconButton, 32px) | 이전 쪽. 화살표(‹) 아이콘과 이름 「이전 페이지」가 붙습니다.                                 |
| `PaginationNext`     | `<button>`(IconButton, 32px) | 다음 쪽. 화살표(›) 아이콘과 이름 「다음 페이지」가 붙습니다.                                 |
| `PaginationEllipsis` | `<span>`(32px)               | 생략 자리. 화면에는 「…」 아이콘, 스크린리더에는 「페이지 생략」이 읽힙니다.                 |

번호는 32px 정사각형부터 시작하고, 두 자리 이상이면 가로 여백 8px로 넓어집니다. 숫자 폭은 같습니다(`tabular-nums`).

### 첫 페이지

처음과 끝에서는 이전/다음에 `disabled`를 줍니다. 쪽 수가 적으면 생략 없이 모두 보입니다.

<Canvas of={PaginationStories.FirstPage} />

### 상태로 페이지 바꾸기

URL을 바꾸지 않고 상태로 쪽을 바꾸면 `PaginationLink`를 `render={<button type="button" onClick={...} />}`로 렌더합니다. 이전/다음은 기본이 `<button>`이라 `onClick`을 바로 줍니다. Next.js에서 링크로 바꾸려면 `render={<NextLink href="?page=2" />}`를 씁니다.

## Do/Don't

### Do: 끝에서는 disabled로 둔다

이전/다음을 지우면 번호 위치가 움직여 사용자가 누르려던 자리가 바뀝니다. 자리를 두고 `disabled`를 줍니다.

<Canvas of={PaginationStories.DoDisableEdges} />

### Don't: 현재 페이지를 표시하지 않는다

`current`가 없으면 화면에서도 스크린리더에서도 지금 몇 쪽인지 알 수 없습니다. 현재 쪽 번호에 `current`를 줍니다.

<Canvas of={PaginationStories.DontNoCurrent} />

## 접근성

### 기본 제공

- 랜드마크: `<nav>`라 탐색 랜드마크이고 기본 이름 「페이지 이동」이 붙습니다. 번호는 목록(`<ul>`)이라 항목 수가 읽힙니다.
- 현재 페이지: `current`인 번호에 `aria-current="page"`가 붙습니다. 색(primary subtle 채움)과 함께 전해집니다.
- 이전/다음: IconButton이라 이름이 늘 있습니다(기본 「이전 페이지」·「다음 페이지」). 화살표 아이콘은 `aria-hidden`입니다. `disabled`는 기본 `<button>`이면 네이티브 disabled(포커스 안 됨), 링크로 렌더하면 `aria-disabled="true"`와 이동 차단입니다.
- 크기: 번호·이전/다음은 32×32px로 WCAG 2.5.8(24×24 이상)을 넘습니다.
- 대비: 번호 `text-default`는 표면 층 위에서, 현재 쪽 `text-primary-on-subtle`은 `bg-primary-subtle` 위에서 4.5:1 이상입니다. hover·누름 배경(`bg-hover`·`bg-active`, `bg-primary-subtle`의 hover·누름) 위에서는 4:1 이상입니다. 생략 아이콘은 장식용입니다.
- 포커스·움직임: Button 규칙과 같습니다. `focus-ring`(outline 2px, offset 2px)을 보이고, 누를 때 줄어드는 반응은 움직임 줄이기에서 꺼집니다. 고대비 모드에서는 투명 border가 경계로 보입니다.

### 앱이 할 일

- 현재 쪽 번호에 `current`를 줍니다.
- 처음·끝 쪽에서 이전/다음에 `disabled`를 줍니다.
- 한 화면에 Pagination이 여럿이면 `aria-label`(예: 「댓글 페이지」)로 구분합니다. 다른 언어 화면에서는 이전/다음 `aria-label`과 생략 텍스트(`PaginationEllipsis`의 children)를 바꿉니다.
- 상태로 쪽을 바꾸면 바뀐 목록의 첫 부분으로 포커스를 옮기거나 결과를 알려 줍니다.

## Props

모두 서버 컴포넌트로 쓸 수 있습니다(번호·이전/다음은 Button·IconButton을 렌더합니다). 부분마다 자기 요소의 props를 받고, `ref`는 그 요소에 연결되며, `className`은 기본 class 뒤에 붙어 충돌하면 이깁니다. `Pagination`의 `ref`·`className`은 `<nav>`에 붙습니다. 색·`variant`·`size` prop은 없습니다(번호·이전/다음은 32px 고정).

| Component                               | 추가·바뀐 prop                                                                                                   | 기본값                            |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | --------------------------------- |
| `Pagination`                            | `aria-label`: `string`                                                                                           | `"페이지 이동"`                   |
| `PaginationLink`                        | `current`: `boolean`                                                                                             | `false`                           |
| `PaginationLink`                        | `render`: `ReactElement`                                                                                         | `<a />`                           |
| `PaginationPrevious` / `PaginationNext` | `aria-label`: `string`(선택)                                                                                     | `"이전 페이지"` / `"다음 페이지"` |
| `PaginationPrevious` / `PaginationNext` | IconButton의 `disabled`·`render`·`noPressScale`·`onClick` 등. `variant`·`color`·`size`·`loading`·`children` 없음 |                                   |
| `PaginationEllipsis`                    | `children`: 스크린리더 텍스트                                                                                    | `"페이지 생략"`                   |
| `PaginationItem`                        | 없음(요소 props 그대로)                                                                                          |                                   |
