# 설치

Next.js App Router 앱에 패키지 하나를 설치하고 CSS 두 줄을 넣으면 Tide Utility class와 Component를 쓸 수 있습니다.

## 준비

- React 19
- Tailwind CSS 4.3 이상과 `@tailwindcss/postcss`

`create-next-app`에서 Tailwind CSS를 골랐다면 이미 준비되어 있습니다. 아니라면 먼저 설치하고 PostCSS 설정을 둡니다.

```sh
pnpm add -D tailwindcss @tailwindcss/postcss
```

```js
// postcss.config.mjs
export default { plugins: { "@tailwindcss/postcss": {} } };
```

## 1. 패키지 설치

`@tide-tds/components` 하나만 설치합니다. `@tide-tds/foundation`(Token, CSS)과 `@tide-tds/icons`(아이콘)는 의존성으로 함께 설치됩니다.

```sh
pnpm add @tide-tds/components
```

## 2. 앱 CSS 두 줄

전역 CSS에 Tailwind CSS, Tide CSS 순서로 씁니다.

```css
/* app/globals.css */
@import "tailwindcss";
@import "@tide-tds/components/styles.css";
```

따로 설정할 것은 없습니다. Tide CSS가 하는 일은 두 가지입니다.

- Tide Token을 Tailwind theme에 연결하고 Tailwind 기본 팔레트 같은 Tide 밖의 값을 지웁니다. 자동완성에 Tide class(`bg-primary-solid`)만 나옵니다.
- Component가 쓰는 class를 Tailwind가 찾도록 패키지 폴더를 스캔 대상에 넣습니다.

## 3. root layout에서 불러오기

```tsx
// app/layout.tsx
import type { ReactNode } from "react";

import "./globals.css";

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <html lang="ko">
      <body>{children}</body>
    </html>
  );
}
```

## 4. 쓰기

Component와 `cn`을 `@tide-tds/components`에서 import합니다. 서버 컴포넌트에서 바로 써도 됩니다. 상호작용하는 Component에는 `"use client"` 경계가 이미 들어 있습니다.

```tsx
// app/page.tsx
import { cn, VisuallyHidden } from "@tide-tds/components";

export default function Page() {
  return (
    <main>
      <h1 className={cn("p-4", "bg-primary-solid")}>Tide</h1>
      <VisuallyHidden>스크린 리더 전용 텍스트</VisuallyHidden>
    </main>
  );
}
```

## 따로 설정하지 않아도 되는 것

- `next.config`의 `transpilePackages`: 넣지 않습니다. Tide는 컴파일된 ESM JavaScript와 타입 선언(`.d.ts`)을 배포합니다.
- TypeScript `moduleResolution`: `bundler`(Next.js 기본값)와 `nodenext` 모두 Tide 타입을 찾습니다.

## 패키지를 직접 설치할 때는 같은 버전으로

`@tide-tds/components`, `@tide-tds/foundation`, `@tide-tds/icons`는 항상 같은 버전으로 함께 릴리스되고, components는 나머지 둘을 정확히 같은 버전으로 의존합니다. foundation이나 icons를 앱에 직접 설치한다면 components와 같은 버전을 적습니다.

```sh
# 예: 0.1.0을 쓰는 경우. 세 패키지의 버전을 맞춘다.
pnpm add @tide-tds/components@0.1.0 @tide-tds/icons@0.1.0
```

버전이 다르면 foundation이 두 벌 설치되어 Token CSS가 두 번 들어가거나 서로 다른 값이 섞일 수 있습니다. 한 벌인지는 아래 명령으로 확인합니다.

```sh
pnpm why @tide-tds/foundation
```

## Tailwind CSS 없이 Token만 쓰기

`@tide-tds/foundation`을 설치하고 tokens CSS를 import합니다. tokens CSS에는 `--tide-*` CSS 변수와 Theme 덮어쓰기(`[data-theme]`)만 들어 있습니다.

```sh
pnpm add @tide-tds/foundation
```

```css
/* app/globals.css */
@import "@tide-tds/foundation/tokens.css";

.call-to-action {
  background-color: var(--tide-bg-primary-solid);
}
```

- 변수 이름: Utility class 이름 앞에 `--tide-`를 붙입니다. `bg-primary-solid`의 값은 `--tide-bg-primary-solid`입니다. 이 이름이 Tailwind CSS 없이 쓰는 사용자와의 약속(공개 계약)입니다.
- 제약: `@tide-tds/components`의 Component는 Tailwind CSS로 스타일을 만들므로 이 방법으로는 쓸 수 없습니다.
