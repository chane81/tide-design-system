# 브랜드 색 더하기

앱의 브랜드 색을 Role로 더하면 `<Button color="brand">`처럼 Tide Role과 같이 씁니다.

## 준비

- [설치](?path=/docs/시작하기-설치--docs)를 마친 앱
- 계열 파일을 `.ts`로 쓰면 Node.js 23.6 이상. 이 버전부터 Node가 TypeScript를 바로 읽습니다. `.js`·`.mjs`로 써도 됩니다.

계열 정의 API와 CLI는 `@tide-tds/foundation`에 있습니다. `@tide-tds/components`와 같은 버전으로 개발 의존성에 더합니다.

```sh
pnpm add -D @tide-tds/foundation@<@tide-tds/components와 같은 버전>
```

## 1. 색 정의하기

50~950의 11단계 스케일 전체를 hex로 적습니다. 이름은 소문자 kebab-case이고 Tide 색 이름(`primary`, `blue` 등)과 겹치면 안 됩니다. 이 이름이 앱 Role 이름이 됩니다.

```ts
// brand.ts
import { defineColorFamily } from "@tide-tds/foundation/color-family";

export default defineColorFamily({
  name: "brand",
  scale: {
    50: "#fcf0f5",
    100: "#fee5f0",
    200: "#ebcbd9",
    300: "#e1adc4",
    400: "#dc7dac",
    500: "#c75b93",
    600: "#a54d7a",
    700: "#90406a",
    800: "#793157",
    900: "#68274a",
    950: "#5c1d3f",
  },
});
```

### 단계별 역할

단계마다 맡는 자리가 정해져 있습니다. 아래는 light Theme 기준입니다. L은 OKLCH 밝기, C는 채도입니다.

| 단계 | 맡는 자리                      | 권장 범위                 |
| ---- | ------------------------------ | ------------------------- |
| 50   | `faint` 바탕                   | —                         |
| 100  | `subtle` 파스텔 바탕           | L 0.945 안팎, C 0.02~0.05 |
| 200  | 파스텔 테두리(`subtle-border`) | —                         |
| 600  | `solid` 바탕, `border`         | 600~900 모두 C 0.13 이하  |
| 700  | `text`(링크 같은 색 글자)      | —                         |
| 950  | 파스텔 글자(`on-subtle`)       | L 0.33~0.36               |

- 범위는 권장이고 대비 검사가 강제하지 않습니다. 계열마다 채도가 조금씩 달라도 됩니다.
- 위 예시 스케일은 이 범위 안에 있고 대비 검사를 통과합니다.
- dark Theme은 950이 파스텔 바탕, 100이 파스텔 글자, 300이 `text`입니다. 전체 규칙은 아래 「대비가 모자랄 때」의 슬롯 표에 있습니다.

## 2. CSS 만들기

`tide-color build`가 Tide 계열과 같은 단계 규칙으로 light·dark CSS를 만듭니다.

```sh
pnpm exec tide-color build brand.ts > app/brand.css
```

대비도 Tide와 같은 기준으로 light·dark 모두 검사합니다. 기준에 못 미치면 모자란 짝을 출력하고, CSS를 만들지 않고 exit 1로 끝납니다.

| 글자·경계                | 배경                                 | 기준  |
| ------------------------ | ------------------------------------ | ----- |
| `text`                   | 표면 층, `faint`, `subtle`           | 4.5:1 |
| `text`                   | `subtle` 누름(Switch thumb, UI 요소) | 3:1   |
| `on-subtle`(파스텔 글자) | `faint`, `subtle`                    | 4.5:1 |
| `on-subtle`(파스텔 글자) | `subtle` 호버·누름                   | 4:1   |
| `on-solid`               | `solid` 3단계                        | 4:1   |
| `border`                 | 표면 층                              | 3:1   |

밝기·채도 범위와 파스텔 테두리는 검사하지 않습니다. 스케일을 바꿀 때마다 다시 실행하도록 `package.json` script로 두면 편합니다.

```json
{
  "scripts": {
    "colors": "tide-color build brand.ts > app/brand.css"
  }
}
```

## 3. CSS 불러오기

Tide CSS 다음 줄에 만든 CSS를 불러옵니다. 순서가 바뀌면 `data-color="brand"`가 적용되지 않습니다.

```css
/* app/globals.css */
@import "tailwindcss";
@import "@tide-tds/components/styles.css";
@import "./brand.css";
```

## 4. Role로 등록하기

`RoleRegistry`에 이름을 더하면 `Role` 타입이 `"brand"`를 받습니다. Button, IconButton, Link의 `color`가 `Role`입니다.

```ts
// app/colors.ts
import type { Role } from "@tide-tds/components";

declare module "@tide-tds/components" {
  interface RoleRegistry {
    brand: true;
  }
}

export const brandRole: Role = "brand";
```

## 5. 쓰기

Component의 `color`에 이름을 줍니다. light·dark Theme도 따라 바뀝니다.

```tsx
// app/page.tsx
<Button color="brand">시작하기</Button>
```

## 상황별 안내

### 대비가 모자랄 때

`overrides`로 슬롯이 가리킬 단계를 바꿉니다. 예를 들어 밝은 노랑은 solid를 밝게 두고 그 위 글자와 `text`를 진한 단계로 바꿉니다.

```ts
// brand.ts
export default defineColorFamily({
  name: "brand",
  scale: yellowScale,
  overrides: {
    solid: { light: 400, dark: 400 },
    "solid-hover": { light: 500, dark: 500 },
    "solid-active": { light: 600, dark: 600 },
    "on-solid": { light: 950, dark: 950 },
    border: { light: 700 },
    text: { light: 800 },
  },
});
```

값은 단계 숫자, `white`·`black`, 덮기(`{ step: 100, overlay: "gray-950", amount: 0.04 }`), 섞기(`{ mix: ["gray-950", 950] }`) 중 하나입니다. Theme 하나만 바꿔도 됩니다. 슬롯과 기본 값은 아래와 같습니다.

### 장식용 색 계열로 쓸 때

Badge·Tag처럼 뜻 없이 색만 구분하는 Component에 쓰려면 `ColorFamilyRegistry`에 더합니다. CSS는 위에서 만든 것을 그대로 씁니다. 두 곳에 함께 등록해도 됩니다.

```ts
// app/colors.ts
declare module "@tide-tds/components" {
  interface ColorFamilyRegistry {
    brand: true;
  }
}
```

### 직접 만든 요소를 칠할 때

`data-color`에 이름을 주고 accent class로 칠합니다.

```tsx
// app/page.tsx
<p data-color="brand" className="bg-accent-solid text-accent-on-solid">
  새 기능
</p>
```

### Tide Role의 색을 바꿀 때

`primary` 같은 Tide Role의 색을 바꾸려면 Role CSS 변수를 Theme별로 덮어씁니다. Tide CSS 다음에 둡니다.

```css
/* app/globals.css */
[data-theme="light"] {
  --tide-bg-primary-solid: #a54d7a;
  --tide-bg-primary-solid-hover: #8e4269;
  --tide-bg-primary-solid-active: #843e62;
  --tide-bg-primary-subtle: #fee5f0;
  --tide-bg-primary-subtle-hover: #f5dde8;
  --tide-bg-primary-subtle-active: #edd6e0;
  --tide-bg-primary-faint: #fcf0f5;
  --tide-text-primary: #90406a;
  --tide-text-primary-on-subtle: #5c1d3f;
  --tide-border-primary: #a54d7a;
  --tide-border-primary-subtle: #ebcbd9;
}
```

- 이 값은 대비 검사를 받지 않습니다. 대비 검사가 필요하면 위처럼 앱 Role을 더합니다.
- 호버·누름 값은 덮은 결과를 직접 넣습니다. `tide-color build`가 만든 CSS의 같은 슬롯 값을 옮기면 됩니다.
- `dark` Theme도 같은 변수를 따로 덮어씁니다.
- `--tide-blue-*` 같은 계열 변수는 덮어쓰지 않습니다. 같은 계열을 쓰는 다른 Role과 장식 색이 함께 바뀝니다.

### 계열이 여러 개일 때

default export를 배열로 두면 한 번에 만듭니다.

```ts
// colors.ts
export default [brand, accentBrand];
```

### 계열 class를 직접 더할 때

`bg-brand-solid` 같은 class가 꼭 필요하면 앱 CSS의 `@theme`에 직접 연결할 수 있습니다. 이 class는 Tide `cn`이 충돌을 풀지 않습니다. 같은 요소에 다른 배경 class와 함께 쓰면 둘 다 남습니다. 되도록 `data-color`와 accent class를 씁니다.

```css
/* app/globals.css */
@theme inline {
  --background-color-brand-solid: var(--tide-brand-solid);
}
```

### Tailwind 없이 쓸 때

계열 변수는 `var(--tide-brand-<슬롯>)`이고, `data-color="brand"` 안에서는 `var(--tide-accent-<슬롯>)`도 브랜드 색입니다.
