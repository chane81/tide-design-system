# Theme 전환

Tide의 Theme은 light와 dark 둘입니다. `data-theme` 속성 하나로 바꿉니다. Tide는 ThemeProvider나 Theme 전환 함수를 배포하지 않습니다. 앱은 속성 값만 바꾸면 되고, 이 페이지의 코드는 그대로 옮겨 쓸 수 있는 예시입니다.

## 속성 하나로 바꾸기

`<html>`에 `data-theme="dark"`를 주면 페이지 전체가 dark Theme이 됩니다.

```html
<html lang="ko" data-theme="dark"></html>
```

- 값은 `light`와 `dark`입니다. 속성이 없으면 light입니다.
- Semantic Token class(`bg-primary-solid` 등)와 Component의 색이 함께 바뀝니다. 브라우저 기본 UI(스크롤바, 폼 요소)도 Theme에 맞게 `color-scheme`이 바뀝니다.
- Tailwind의 `dark:` variant는 `data-theme="dark"`를 따릅니다.

## 요소 단위 Theme

`data-theme`은 `<html>`이 아닌 요소에도 줄 수 있습니다. 그 요소 안쪽만 그 Theme이 됩니다. 페이지 일부만 다른 Theme으로 보여 줄 때 씁니다.

```tsx
<main>
  <p>페이지의 Theme을 따릅니다.</p>
  <section data-theme="dark" className="bg-canvas text-default">
    <p>이 영역 안은 dark Theme입니다.</p>
  </section>
</main>
```

영역에는 배경과 글자색 class(`bg-canvas text-default`)를 함께 줍니다. 속성만 주면 영역 안의 Component와 Token class는 바뀌지만, 바깥에서 물려받은 배경과 글자색은 그대로 남습니다.

`dark:` variant는 조상 중 하나라도 `data-theme="dark"`이면 적용됩니다. 그래서 dark 페이지 안에 둔 light 영역에서도 `dark:` class가 적용됩니다. 영역 단위로 Theme을 섞는다면 `dark:` 대신 Semantic Token class를 씁니다. Semantic Token은 가장 가까운 `data-theme`을 따릅니다.

## OS 설정을 따를지는 앱이 정합니다

Tide는 OS의 다크 모드 설정(`prefers-color-scheme`)을 읽지 않습니다. `data-theme`이 없으면 OS가 dark여도 light입니다. OS 설정을 따를지, 사용자가 고른 Theme을 기억할지는 앱이 정합니다.

서버는 사용자의 선택을 모른 채 렌더하므로, 브라우저가 화면을 그리기 전에 `data-theme`을 정해야 깜빡임이 없습니다. Next.js 공식 가이드([How to prevent flash before hydration](https://nextjs.org/docs/app/guides/preventing-flash-before-hydration))처럼 root layout의 `<head>`에 인라인 스크립트를 둡니다. 아래 예시는 저장된 선택이 있으면 그것을, 없으면 OS 설정을 따릅니다. OS 설정을 따르지 않으려면 `matchMedia` 부분을 지우고 `"light"`를 기본값으로 둡니다.

```tsx
// app/layout.tsx
import type { ReactNode } from "react";

import "./globals.css";

// 첫 화면을 그리기 전에 실행된다. localStorage를 쓸 수 없는 환경에서는 light로 남는다.
const themeScript = `(function(){try{
  var t = localStorage.getItem("theme");
  if (t !== "light" && t !== "dark") {
    t = matchMedia("(prefers-color-scheme: dark)").matches ? "dark" : "light";
  }
  document.documentElement.setAttribute("data-theme", t);
}catch(e){}})()`;

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    // 스크립트가 서버가 렌더한 속성을 바꾸므로 suppressHydrationWarning을 붙인다.
    <html lang="ko" data-theme="light" suppressHydrationWarning>
      <head>
        <script dangerouslySetInnerHTML={{ __html: themeScript }} />
      </head>
      <body>{children}</body>
    </html>
  );
}
```

엄격한 CSP를 쓰는 앱은 이 인라인 스크립트에 nonce를 붙여야 합니다.

## 전환 순간에는 transition을 끕니다

Component에는 hover 같은 상태 변화를 위한 transition이 있습니다. 색 전환은 `transition-colors`이고 시간은 `duration-fast`(`--tide-duration-fast`, 150ms)입니다([움직임](?path=/docs/foundation-움직임--docs)). Theme을 바꿀 때 이 transition이 그대로 돌면 요소마다 색이 따로 천천히 바뀌어 화면이 어수선해집니다. 바꾸는 순간에만 transition을 끄면 모든 색이 한꺼번에 바뀝니다.

```ts
// theme.ts — 사용자가 Theme을 고를 때 부르는 함수(클라이언트에서만 실행)
export type Theme = "light" | "dark";

export function setTheme(theme: Theme): void {
  const root = document.documentElement;

  // 1. 모든 transition을 잠시 끈다.
  const style = document.createElement("style");
  style.textContent = "*, *::before, *::after { transition: none !important; }";
  document.head.append(style);

  // 2. Theme을 바꾼다.
  root.dataset.theme = theme;

  // 3. reflow를 강제해 transition 없이 새 색을 확정한 뒤, 다음 frame에 원래대로 돌린다.
  void root.offsetHeight;
  requestAnimationFrame(() => style.remove());

  try {
    localStorage.setItem("theme", theme);
  } catch {
    // 저장할 수 없어도 Theme은 바뀐다.
  }
}
```

전환 버튼은 클라이언트 컴포넌트로 만듭니다.

```tsx
// ThemeToggle.tsx
"use client";

import { useEffect, useState } from "react";

import { setTheme, type Theme } from "./theme";

export function ThemeToggle() {
  const [theme, setThemeState] = useState<Theme>("light");

  // 인라인 스크립트가 정한 값을 읽어 온다.
  useEffect(() => {
    setThemeState(document.documentElement.dataset.theme === "dark" ? "dark" : "light");
  }, []);

  return (
    <button
      type="button"
      aria-pressed={theme === "dark"}
      onClick={() => {
        const next = theme === "dark" ? "light" : "dark";
        setTheme(next);
        setThemeState(next);
      }}
    >
      dark Theme
    </button>
  );
}
```

이 문서 사이트도 같은 방법을 씁니다. 상단 툴바의 Theme 버튼을 눌러 보세요.
