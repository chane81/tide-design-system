# 폰트 로드

Tide의 기본 글꼴은 [Pretendard](https://github.com/orioncactus/pretendard)의 가변 글꼴(`Pretendard Variable`)입니다. Tide는 글꼴 이름이 든 font-family 스택만 제공하고, 글꼴 파일과 `@font-face`는 배포하지 않습니다. 웹폰트는 앱이 불러옵니다. 그래야 Tide 패키지가 무거워지지 않습니다.

Tide의 `sans` 스택은 아래 순서입니다. 앱이 Pretendard를 불러오지 않으면 다음 순서의 시스템 글꼴로 그립니다.

```css
"Pretendard Variable", Pretendard, -apple-system, BlinkMacSystemFont, system-ui, Roboto,
  "Helvetica Neue", "Segoe UI", "Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic",
  "Apple Color Emoji", "Segoe UI Emoji", "Segoe UI Symbol", sans-serif
```

고정폭 글꼴 `mono`는 시스템 글꼴만 쓰므로 불러올 것이 없습니다.

방법은 둘입니다.

| 방법                            | 내려받는 양                                              | 앱이 할 일                                     |
| ------------------------------- | -------------------------------------------------------- | ---------------------------------------------- |
| CDN 가변 동적 subset            | 페이지에 쓰인 글자가 든 조각만(조각당 약 8~44KB)         | `<link>` 한 줄                                 |
| `next/font/local`로 직접 호스팅 | 글꼴 파일 하나 전체(한글 11,172자 가변 woff2, 약 2.06MB) | 글꼴 파일을 앱에 넣고 CSS 변수 하나를 연결한다 |

## CDN 가변 동적 subset

Pretendard가 공식으로 배포하는 가변 동적 subset CSS를 root layout의 `<head>`에 넣습니다. 이 CSS는 글꼴을 `unicode-range` 조각 92개로 나눠 두어서, 브라우저는 페이지에 실제로 쓰인 글자가 든 조각만 내려받습니다.

```tsx
// app/layout.tsx
import type { ReactNode } from "react";

import "./globals.css";

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <html lang="ko">
      <head>
        <link
          rel="stylesheet"
          href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css"
        />
      </head>
      <body>{children}</body>
    </html>
  );
}
```

이 CSS가 선언하는 글꼴 이름이 `Pretendard Variable`이라서 Tide 스택의 첫 이름과 같습니다. 그래서 따로 연결할 것이 없습니다.

- 주소의 버전(`v1.3.9`)은 고정해 둡니다. 버전 없이 쓰면 글꼴이 예고 없이 바뀔 수 있습니다.
- jsDelivr 대신 cdnjs나 UNPKG 주소도 [Pretendard README](https://github.com/orioncactus/pretendard/blob/main/packages/pretendard/README.md)에 있습니다.

## `next/font/local`로 직접 호스팅

외부 CDN에 요청하지 않으려면 글꼴 파일을 앱에 넣고 `next/font/local`로 불러옵니다.

1. Pretendard 저장소의 v1.3.9 태그에서 [`PretendardVariable.woff2`](https://github.com/orioncactus/pretendard/blob/v1.3.9/packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2)를 받아 `app/fonts/`에 넣습니다.
2. root layout에서 `localFont`로 불러오고, `variable`로 정한 CSS 변수를 `<html>`에 붙입니다.

```tsx
// app/layout.tsx
import localFont from "next/font/local";
import type { ReactNode } from "react";

import "./globals.css";

const pretendard = localFont({
  // 경로는 이 파일 위치 기준이다.
  src: "./fonts/PretendardVariable.woff2",
  // 가변 글꼴이므로 굵기 범위를 준다.
  weight: "45 920",
  display: "swap",
  variable: "--font-pretendard",
});

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <html lang="ko" className={pretendard.variable}>
      <body>{children}</body>
    </html>
  );
}
```

3. 앱 CSS에서 그 변수를 Tide `sans` 스택의 맨 앞에 넣습니다.

```css
/* app/globals.css */
@import "tailwindcss";
@import "@tide-tds/desktop/styles.css";

:root {
  --tide-font-sans:
    var(--font-pretendard), -apple-system, BlinkMacSystemFont, system-ui, Roboto, "Helvetica Neue",
    "Segoe UI", "Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", "Apple Color Emoji",
    "Segoe UI Emoji", "Segoe UI Symbol", sans-serif;
}
```

`next/font`가 선언하는 글꼴 이름은 `Pretendard Variable`이 아니라 `next/font`가 정한 이름입니다. 그래서 Tide 스택의 첫 이름으로는 이 글꼴을 찾지 못하고, `variable`로 받은 CSS 변수로 연결해야 합니다. `--tide-font-sans`는 `font-sans` class와 기본 글꼴이 쓰는 값입니다.

root layout에서 불러온 글꼴은 모든 페이지에서 미리 내려받습니다(preload). 파일 하나가 약 2MB이므로, 첫 방문 용량이 중요하다면 CDN 가변 동적 subset이 더 가볍습니다.
