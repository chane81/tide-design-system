# Menu

트리거를 누르면 동작 목록을 띄우는 오버레이입니다. 화살표로 항목을 옮겨 다니고 Enter로 실행하며, 지금 위치는 배경 강조(highlight)로 보입니다. 실행하거나 Esc·바깥 누름·Tab으로 닫으면 포커스는 트리거로 돌아옵니다.

<Canvas of={MenuStories.Basic} />

## 사용 시점

- 지금 대상(문서, 댓글, 행)에 할 수 있는 동작을 여러 개 모아 둘 때(이름 바꾸기, 복제, 삭제)
- 자리가 좁아 동작 버튼을 늘어놓기 어려울 때(「더보기」 IconButton)

## 쓰지 않을 때

- 폼 값 하나를 고를 때는 Select·Combobox를 씁니다. 고른 값이 트리거에 보이고 폼 제출에 들어갑니다.
- 페이지 이동 목록(내비게이션)은 링크 목록을 씁니다. Menu 항목은 링크가 아닙니다.
- 설정·입력 같은 조작 요소를 담을 때는 Popover를 씁니다. Menu 안에는 항목만 둘 수 있습니다.
- 동작이 하나나 둘이면 Button을 그대로 둡니다.

## 예시

### 트리거

`MenuTrigger`는 기본으로 class 없는 `<button>`입니다. Tide Button 모양을 쓰려면 `render={<Button />}`를 줍니다. 아이콘만 있는 트리거는 `render={<IconButton aria-label="…" />}`로 이름을 붙입니다. 목록에 이름이 따로 없으면 트리거 이름이 목록(`menu`)의 이름이 됩니다.

<Canvas of={MenuStories.IconTrigger} />

### 묶음과 비활성 항목

`MenuSection`으로 항목을 묶고 `heading`으로 제목을 붙입니다. 제목은 묶음의 이름이 되고, 묶음 앞뒤에는 구분선이 그려집니다. 제목이 없으면 `aria-label`로 이름을 줍니다. `disabled` 항목은 흐리게 보이고 실행되지 않으며 키보드 위치가 건너뜁니다.

<Canvas of={MenuStories.Sections} />

### 실행과 위치

항목의 `onClick`은 마우스·터치 누름과 Enter·Space에서 모두 불리고, 부른 뒤 메뉴가 닫힙니다. `placement`(기본 `bottom start`)로 트리거의 어느 쪽에 띄울지 정하고, 공간이 모자라면 반대쪽으로 뒤집힙니다. 간격은 `offset`(기본 4px)입니다.

## 접근성

### 기본 제공

- 역할: 트리거는 버튼이고 `aria-haspopup`, `aria-expanded`, 열렸을 때 `aria-controls`가 붙습니다. 목록은 `menu`, 항목은 `menuitem`, 묶음은 `group`, 구분선은 `separator` 역할입니다(React Aria `useMenuTrigger`·`useMenu`·`useMenuItem`·`useMenuSection`).
- 열기: 마우스는 누르는 순간 열리고 목록에 포커스가 옵니다. 키보드는 Enter·Space·↓로 열면 첫 항목, ↑로 열면 마지막 항목에 위치합니다.
- 탐색: ↓↑로 옮기고 끝에서 처음으로 돕니다. Home·End는 처음·마지막 항목입니다. 영문 글자를 치면 그 글자로 시작하는 항목으로 옮겨 갑니다. 비활성 항목은 건너뜁니다.
- 실행: Enter·Space·누름. 실행하면 닫히고 포커스가 트리거로 돌아옵니다.
- 닫기: Esc, 바깥 누름, Tab. 열린 동안 바깥은 `inert`라 읽히지도 눌리지도 않고 페이지 스크롤이 잠깁니다.
- 위치 표시(highlight): 키보드 위치와 마우스를 올린 항목은 primary subtle 배경과 primary 글자로 바로 바뀝니다(전환 없음). 고대비 모드(forced-colors)에서는 배경 대신 항목 안쪽 2px 테두리가 시스템 색으로 그려져 위치가 보입니다.
- 대비: 항목 글자(`text-default`)는 raised 표면과, highlight 글자(`text-primary`)는 primary subtle 배경과 4.5:1 이상입니다. 경계·구분선은 장식용이라 대비 검사 대상이 아닙니다.
- 움직임: 바로 나타나고 사라질 때만 opacity가 짧게(150ms) 흐려집니다. 이동·blur가 없어 움직임 줄이기에서도 같습니다.

### 앱이 할 일

- 아이콘만 있는 트리거에는 `aria-label`을 줍니다(IconButton은 타입상 필수입니다).
- 항목 내용이 글자가 아니면(아이콘만 있으면) `aria-label`을, 타입어헤드 글자가 내용과 다르면 `textValue`를 줍니다.
- `MenuItem`·`MenuSection`은 `MenuContent`(또는 `MenuSection`) 바로 안에 둡니다. Fragment와 배열(`map`)은 되지만, 직접 만든 Component로 항목을 감싸면 모이지 않습니다.
- 한글 글자로는 타입어헤드가 되지 않습니다(입력기가 조합하는 동안 글자 키가 오지 않습니다). 항목이 많으면 묶음으로 나눕니다.

## Props

모두 client Component입니다. `Menu`는 DOM 요소가 없고 열림 상태만 갖습니다. `MenuTrigger`는 `<button>`, `MenuContent`·`MenuItem`은 `<div>`의 props를 받고 `ref`는 그 요소에 연결되며, `className`은 기본 class 뒤에 붙어 충돌하면 이깁니다. 색·`variant`·`size` prop은 없습니다.

| Component     | prop                                   | 기본값                         |
| ------------- | -------------------------------------- | ------------------------------ |
| `Menu`        | `open`: `boolean`(제어)                | 없음                           |
| `Menu`        | `defaultOpen`: `boolean`(비제어)       | `false`                        |
| `Menu`        | `onOpenChange`: `(open) => void`       | 없음                           |
| `MenuTrigger` | `render`: `ReactElement`               | 없음(`<button type="button">`) |
| `MenuContent` | `placement`: `MenuPlacement`           | `"bottom start"`               |
| `MenuContent` | `offset`: `number`(px)                 | `4`                            |
| `MenuContent` | `role`·`id` 제외(menu, 자동 id)        |                                |
| `MenuItem`    | `onClick`: 실행할 때(키보드 포함)      | 없음                           |
| `MenuItem`    | `disabled`: `boolean`                  | `false`                        |
| `MenuItem`    | `textValue`: `string`(타입어헤드 글자) | 내용의 글자                    |
| `MenuItem`    | `role` 제외(menuitem)                  |                                |
| `MenuSection` | `heading`: `ReactNode`(제목이자 이름)  | 없음                           |
| `MenuSection` | `aria-label`: `string`(제목이 없을 때) | 없음                           |
| `MenuSection` | `className`: 묶음 감싸개 class         | 없음                           |

상태는 `data-open`(트리거와 목록, 열렸을 때), `data-placement`(목록, `top`/`bottom`/`left`/`right`), `data-highlighted`(항목, 키보드 위치·hover), `data-disabled`(항목, 비활성)로 노출합니다.
