# Spinner

끝나는 시점을 알 수 없는 짧은 기다림 동안 로딩 중임을 알리는 회전 표시입니다.

<Canvas of={SpinnerStories.Basic} />

## 사용 시점

- 요청 보내기, 목록 불러오기처럼 짧게 기다릴 때
- 버튼을 누른 뒤 결과를 기다리는 동안 버튼 안에서

## 쓰지 않을 때

- 진행률을 알 수 있으면 Progress를 씁니다.
- 불러올 내용의 자리와 모양을 미리 보여 줄 수 있으면 Skeleton을 씁니다. 화면이 덜 흔들립니다.
- 한 영역에 하나만 둡니다.

## 예시

### 크기 바꾸기

| `size`     | 크기 | 선 두께 |
| ---------- | ---- | ------- |
| `xs`, `sm` | 14px | 2px     |
| `md`(기본) | 16px | 2px     |
| `lg`       | 20px | 2px     |

같은 size Component의 텍스트 옆 아이콘과 크기가 같아, Button 로딩 상태의 아이콘 자리에 그대로 들어갑니다.

<Canvas of={SpinnerStories.Sizes} />

### 이름 바꾸기

기본 이름은 「로딩 중」입니다. `aria-label`에 무엇을 불러오는지 적으면 스크린 리더 사용자가 문맥을 압니다.

<Canvas of={SpinnerStories.Label} />

### 보이는 텍스트를 이름으로 쓰기

옆에 설명 텍스트가 있으면 `aria-labelledby`로 연결합니다. 번역 도구가 이름도 함께 옮깁니다.

<Canvas of={SpinnerStories.LabelledBy} />

### 색 바꾸기

색은 주변 글자색(`currentColor`)을 따릅니다. `className`이나 부모에 글자색 Semantic Token(`text-muted`, `text-primary` 등)을 줍니다. 대비는 그 Token의 대비 쌍이 보장합니다.

<Canvas of={SpinnerStories.WithColor} />

### 버튼 안에 넣기

버튼 텍스트가 이미 로딩 중임을 말하면 Spinner에 `aria-hidden="true"`를 줍니다. 버튼의 로딩 상태 동작은 Button에서 정합니다.

<Canvas of={SpinnerStories.InButton} />

## Do/Don't

### Do: 무엇을 불러오는지 적는다

<Canvas of={SpinnerStories.DoSpecificLabel} />

### Don't: 보이는 텍스트와 이름을 겹친다

스크린 리더가 「로딩 중」을 두 번 읽습니다. 텍스트를 `aria-labelledby`로 연결하거나 Spinner를 `aria-hidden="true"`로 숨깁니다.

<Canvas of={SpinnerStories.DontDuplicateLabel} />

## 접근성

### 기본 제공

- 역할: `status`. 이름은 「로딩 중」입니다.
- 포커스: 받지 않습니다(`focusable="false"`, tabindex 없음).
- 회전: 1초에 한 바퀴(`animate-spin`)입니다.
- 움직임 줄이기: 켜도 멈추지 않습니다. 로딩 여부 자체가 정보이고, 이동·확대 없이 작게 돌아 화면을 흔들지 않습니다([움직임](?path=/docs/foundation-움직임--docs)).
- 고대비 모드(forced-colors): 시스템 글자색으로 그려집니다.

### 앱이 할 일

- 로딩이 끝났다는 사실이나 결과처럼 꼭 들어야 하는 내용은, 처음부터 있던 알림 영역에 텍스트로 넣습니다. 새로 넣은 `status`를 바로 읽는지는 스크린 리더마다 다릅니다.

## Props

서버 컴포넌트로 쓸 수 있습니다. `svg`의 props를 모두 받습니다(`children` 제외). `ref`는 `svg`에 연결되고, `className`은 기본 class 뒤에 붙어 충돌하면 이깁니다(예: `size-8`).
