# VisuallyHidden

화면에는 보이지 않고 스크린 리더 같은 보조 기술에만 읽히는 텍스트입니다.

## 사용 시점

- 아이콘만 있는 버튼이나 링크에 접근 가능한 이름을 붙일 때
- 화면에서는 주변 문맥으로 알 수 있지만, 텍스트만 읽으면 모호한 정보를 덧붙일 때

## 쓰지 않을 때

- 모든 사용자에게 필요한 정보라면 화면에 보이게 씁니다.
- 번역이나 검색이 필요 없는 짧은 이름이면 요소에 `aria-label`을 줘도 됩니다.
- 포커스를 받는 요소(링크, 버튼)를 숨기는 데 쓰지 않습니다. 보이지 않는 곳으로 포커스가 이동합니다.

## 접근성

### 기본 제공

- 텍스트는 접근성 트리에 남아 이름으로 읽힙니다. `display: none`이나 `hidden`과 달리 보조 기술에서도 사라지지 않습니다.
- 루트 요소는 `span`입니다. 문장 안이나 버튼 안 어디에 넣어도 레이아웃을 바꾸지 않습니다.

### 앱이 할 일

- 아이콘은 `aria-hidden="true"`로 숨기고, 이름은 VisuallyHidden 텍스트로 줍니다.

## Props

서버 컴포넌트로 쓸 수 있습니다. `span`의 props를 모두 받고, 표에는 자주 쓰는 prop만 적었습니다. `ref`는 `span`에 연결되고, `className`은 기본 class 뒤에 붙어 충돌하면 이깁니다.
