# Tag

사용자가 고르거나 입력한 값을 보여 주는 짧은 라벨 묶음입니다. 필요하면 지울 수 있습니다. 키보드로는 ←→로 태그를 옮겨 다니고 Delete로 지웁니다.

<Canvas of={TagStories.Basic} />

## 사용 시점

- 사용자가 고른 필터·입력한 키워드처럼, 보고 나서 하나씩 지울 수 있어야 하는 값을 보여 줄 때
- 받는 사람·권한처럼 여러 값이 한 묶음으로 쌓이는 입력의 결과를 보여 줄 때

## 쓰지 않을 때

- 상태(완료·실패)나 바뀌지 않는 분류 라벨처럼 상호작용이 없는 표시는 Badge를 씁니다. Badge는 서버 컴포넌트로 쓸 수 있습니다.
- 눌러서 켜고 끄는 선택(토글 칩)은 Tag가 아닙니다. Checkbox나 Switch를 씁니다.
- 이동이 목적이면 Link를 씁니다.

## 예시

### 지우기

`TagGroup`에 `onRemove`를 주면 태그마다 끝에 지우기 버튼이 생기고 Delete·Backspace로도 지웁니다. `onRemove`는 지울 태그의 `value`로 불리고, 목록에서 빼는 일은 앱이 합니다. 지운 뒤 포커스는 다음 태그(없으면 앞 태그)로 옮겨 갑니다.

### 색 계열

분류마다 뜻 없는 색 계열(`gray`·`blue`·`green`·`amber`·`red`·`cyan`, 장식 계열 `purple`·`mint`, 앱 장식 계열)을 `Tag`의 `color`로 고릅니다. 기본값은 `gray`입니다. Role(`primary`·`danger` 등)은 받지 않습니다.

<Canvas of={TagStories.Colors} />

### 지우지 않는 태그

`onRemove`가 없으면 지우기 버튼이 없습니다. 태그 글자 앞에 장식용 아이콘을 둘 수 있습니다.

<Canvas of={TagStories.ReadOnly} />

### 비활성 태그

`disabled` 태그는 흐리게 보이고 지울 수 없으며, 키보드 이동도 건너뜁니다.

<Canvas of={TagStories.Disabled} />

### 보이는 제목으로 이름 짓기

화면에 제목이 있으면 `aria-labelledby`로 그 제목을 묶음 이름으로 씁니다.

## 접근성

### 기본 제공

- 구조: 묶음은 `grid` 역할, 태그는 `row` 안의 `gridcell`입니다(React Aria `useTagGroup`·`useTag`). 태그가 모두 지워지면 묶음은 `group` 역할이 됩니다.
- 키보드: Tab 자리는 묶음 안의 태그 하나입니다. ←→로 옮기고(끝에서 처음으로 돕니다, 오른쪽에서 왼쪽으로 쓰는 locale은 반대) Home·End로 처음·마지막 태그에 갑니다. 비활성 태그는 건너뜁니다. Delete·Backspace로 지웁니다.
- 지운 뒤 포커스: 다음 태그로, 마지막이면 앞 태그로 옮겨 갑니다. 모두 지우면 묶음에 남습니다.
- 지우기 버튼: 이름은 「`removeLabel` + 태그 글자」(예: 「제거 디자인」)이고 24×24px입니다. 키보드는 태그에서 Delete로 지우므로 버튼은 Tab 순서에서 빠집니다. 키보드로 태그에 오면 Delete 안내가 설명으로 읽힙니다(React Aria 번역, locale을 따릅니다).
- 알림: 묶음에 포커스가 있는 동안 태그가 더해지면 스크린 리더가 읽습니다(`aria-live="polite"`).
- 포커스 표시: 키보드 포커스에 요소에 붙은 3px halo(`focus-ring`)가 보입니다.
- 대비: 태그 글자와 지우기 아이콘(파스텔 글자 `on-subtle`)은 같은 계열 subtle 배경에서 4.5:1, 지우기 버튼의 hover·누름 배경에서 4:1, ring은 3:1 이상입니다. 파스텔 테두리는 꾸밈이라 대비 검사 대상이 아닙니다. 비활성 태그도 대비 검사 대상이 아닙니다.
- 고대비 모드(forced-colors): 경계가 시스템 색으로 보여 배경 없이도 태그 모양이 남고, 지우기 아이콘은 버튼 글자의 시스템 색을 따릅니다.

### 앱이 할 일

- 묶음 이름을 `aria-label`이나 `aria-labelledby`로 꼭 줍니다(타입상 필수).
- 한 화면에 묶음이 여럿이면 `removeLabel`을 그대로 두어도 버튼 이름에 태그 글자가 붙어 구분됩니다. 같은 글자의 태그가 두 묶음에 있으면 묶음 이름으로 구분합니다.
- `Tag`는 `TagGroup` 바로 아래(또는 Fragment·배열 안)에 둡니다. 앱이 만든 Component로 감싸면 모이지 않습니다.
- 색만으로 분류의 뜻을 전하지 않습니다. 뜻은 태그 글자로 적습니다.

## Props

모두 client Component입니다. `TagGroup`과 `Tag`는 `<div>`의 props를 받고 `ref`는 그 요소(묶음 `grid`, 태그 `row`)에 연결되며, `className`은 기본 class 뒤에 붙어 충돌하면 이깁니다. `variant`·`size` prop은 없습니다(높이 32px 하나).

| Component  | prop                                                                  | 기본값   |
| ---------- | --------------------------------------------------------------------- | -------- |
| `TagGroup` | `aria-label` 또는 `aria-labelledby`(둘 중 하나 필수)                  |          |
| `TagGroup` | `onRemove`: `(value: string) => void`(주면 지우기 버튼과 Delete 제거) | 없음     |
| `TagGroup` | `removeLabel`: `string`(지우기 버튼 이름 앞부분)                      | `"제거"` |
| `TagGroup` | `role` 제외(`grid`, 비면 `group`)                                     |          |
| `Tag`      | `value`: `string`(필수, `onRemove`에 넘어오는 값)                     |          |
| `Tag`      | `children`: `ReactNode`(필수, 태그 글자)                              |          |
| `Tag`      | `color`: `ColorFamilyName`(Tide 색 계열 8개 + 앱 장식 계열)           | `"gray"` |
| `Tag`      | `disabled`: `boolean`                                                 | `false`  |
| `Tag`      | `textValue`: `string`(태그 행 이름이 되는 글자, 기본은 children 글자) | 없음     |
| `Tag`      | `role`·`id`·`tabIndex` 제외(React Aria가 정함)                        |          |

상태는 `aria-disabled`(비활성 태그)와 `data-color`(태그)로 노출합니다.
