# Tabs

같은 영역에서 여러 패널 중 하나를 골라 보여 주는 탭 묶음입니다. 화살표로 탭을 옮기고, 고른 탭은 primary 글자와 아래 막대로 보입니다.

<Canvas of={TabsStories.Basic} />

## 사용 시점

- 같은 대상의 내용을 같은 수준의 묶음으로 나눌 때(프로젝트의 개요·활동 기록·설정)
- 한 번에 하나만 보면 되고, 묶음 사이를 자주 오갈 때

## 쓰지 않을 때

- 차례대로 거쳐야 하는 단계는 한 화면씩 진행하는 흐름으로 둡니다. 탭은 아무 순서로나 고를 수 있습니다.
- 여러 묶음을 함께 펼쳐 볼 수 있어야 하면 Accordion을 씁니다.
- 다른 페이지로 이동하는 메뉴는 링크 목록(내비게이션)을 씁니다. 탭은 같은 페이지 안의 패널을 바꿉니다.

## 예시

### 고른 값 정하기

`Tab`과 `TabPanel`은 같은 `value`로 이어집니다. 처음 고를 탭은 `defaultValue`로 정합니다. `value`나 `defaultValue` 중 하나는 꼭 줍니다. 그래야 서버 렌더에서도 패널이 바로 보입니다.

### 아이콘과 비활성 탭

탭 안에 아이콘(장식용)과 글자를 함께 둡니다. `disabled` 탭은 흐리게 보이고 고를 수 없으며, 키보드 이동이 건너뜁니다.

<Canvas of={TabsStories.IconsAndDisabled} />

### 세로로 놓기

`orientation="vertical"`이면 탭 목록이 패널의 시작쪽에 서고 ↓↑로 옮깁니다. 고른 막대는 탭의 끝쪽에 그려집니다.

<Canvas of={TabsStories.Vertical} />

### 고를 때까지 기다리기

기본은 화살표로 옮기면 바로 그 탭을 고릅니다. 패널을 그리는 데 시간이 걸리면 `activationMode="manual"`로 둡니다. 화살표는 포커스만 옮기고 Enter·Space로 고릅니다.

<Canvas of={TabsStories.Manual} />

### 앱 상태로 제어하기

`value`와 `onValueChange`로 고른 값을 앱 상태로 둡니다. 탭 밖의 버튼으로도 값을 바꿀 수 있습니다.

## 접근성

### 기본 제공

- 역할: 탭 목록은 `tablist`(`aria-orientation`), 탭은 `tab`, 패널은 `tabpanel`입니다(React Aria `useTabList`·`useTab`). 고른 탭은 `aria-selected="true"`이고 `aria-controls`로 패널을 가리킵니다. 패널은 `aria-labelledby`로 탭 이름을 받습니다.
- 들어가기: Tab으로 탭 목록에 들어오면 고른 탭에 포커스가 옵니다. 다음 Tab은 패널로 갑니다.
- 탐색: →←(세로면 ↓↑)로 옮기고 끝에서 처음으로 돕니다. Home·End는 처음·마지막 탭입니다. 비활성 탭은 건너뜁니다.
- 오른쪽에서 왼쪽으로 쓰는 locale(아랍어 등)에서는 ←가 다음 탭입니다. React Aria `I18nProvider`의 locale을 따릅니다.
- 포커스 표시: 키보드 포커스에 ring(2px, 2px 떨어짐)이 보입니다. 패널도 같습니다.
- 고른 표시: 글자색만이 아니라 2px 막대로도 구분됩니다. 고대비 모드(forced-colors)에서는 막대가 시스템 강조색으로 그려집니다.
- 대비: 탭 글자(`text-muted`, `text-primary`)는 표면 층과 4.5:1, 고른 막대(`border-primary`)와 ring은 3:1 이상입니다. 탭 목록 선은 장식용이라 대비 검사 대상이 아닙니다.
- 움직임: 고른 막대는 가운데에서 짧게(150ms) 펼쳐집니다. 움직임 줄이기에서는 펼침 없이 흐려졌다 나타나기만 합니다.

### 앱이 할 일

- `TabList`에 `aria-label`(또는 보이는 제목을 가리키는 `aria-labelledby`)로 이름을 줍니다.
- 아이콘만 있는 탭에는 `aria-label`을 줍니다.
- `Tab`은 `TabList` 바로 안에 둡니다. Fragment와 배열(`map`)은 되지만, 직접 만든 Component로 탭을 감싸면 모이지 않습니다.
- 앱이 `dir="rtl"`만 주고 locale을 바꾸지 않으면 화살표 방향은 바뀌지 않습니다. RTL 앱은 `I18nProvider`로 locale을 줍니다.
- 패널의 첫 내용이 버튼·입력 같은 조작 요소면 `tabIndex={-1}`로 패널을 Tab 순서에서 뺄 수 있습니다.

## Props

모두 client Component입니다. `Tabs`·`TabList`·`TabPanel`은 `<div>`, `Tab`은 `<button type="button">`의 props를 받고 `ref`는 그 요소에 연결되며, `className`은 기본 class 뒤에 붙어 충돌하면 이깁니다. 색·`variant`·`size` prop은 없습니다.

| Component  | prop                                                    | 기본값         |
| ---------- | ------------------------------------------------------- | -------------- |
| `Tabs`     | `value`: `string`(제어)                                 | 없음           |
| `Tabs`     | `defaultValue`: `string`(비제어, `value`가 없으면 필수) | 없음           |
| `Tabs`     | `onValueChange`: `(value) => void`                      | 없음           |
| `Tabs`     | `orientation`: `"horizontal" \| "vertical"`             | `"horizontal"` |
| `Tabs`     | `activationMode`: `"automatic" \| "manual"`             | `"automatic"`  |
| `TabList`  | `aria-label`·`aria-labelledby`: 이름                    | 없음           |
| `TabList`  | `role` 제외(tablist)                                    |                |
| `Tab`      | `value`: `string`(필수)                                 |                |
| `Tab`      | `disabled`: `boolean`                                   | `false`        |
| `Tab`      | `role`·`type`·`id` 제외(tab, 자동 id)                   |                |
| `TabPanel` | `value`: `string`(필수, 이어지는 탭의 값)               |                |
| `TabPanel` | `tabIndex`: `number`                                    | `0`            |
| `TabPanel` | `role`·`id` 제외(tabpanel, 자동 id)                     |                |

상태는 `data-orientation`(루트, `horizontal`/`vertical`), `data-selected`(고른 탭), `:disabled`(비활성 탭)로 노출합니다.
