# Select

목록에서 값 하나를 고르는 입력입니다. 트리거는 입력창 모양이고 고른 옵션이 보입니다. 누르면 옵션 목록이 열리고, 고르면 닫히며 포커스가 트리거로 돌아옵니다. `Field` 안에 두면 label·설명·오류가 자동으로 연결되고, `name`을 주면 고른 값이 폼에 제출됩니다.

<Canvas of={SelectStories.Basic} />

## 사용 시점

- 정해진 옵션 몇 개(대략 5~15개) 중 하나를 고를 때(국가, 정렬 기준, 배송 지역)
- 옵션이 길어 라디오 버튼으로 늘어놓기에 자리가 모자랄 때

## 쓰지 않을 때

- 옵션이 2~4개이고 모두 보여 줘야 고르기 쉬우면 RadioGroup을 씁니다.
- 옵션이 많아 찾아야 하면(수십 개 이상) 글자를 쳐서 거르는 Combobox를 씁니다.
- 여러 개를 고르면 CheckboxGroup을 씁니다. Select는 하나만 고릅니다.
- 동작을 실행할 때(이름 바꾸기, 삭제)는 Menu를 씁니다. Select는 고른 값이 남는 폼 입력입니다.

## 예시

### size

`size`는 `sm`(32px)·`md`(40px, 기본값)·`lg`(48px)이고 같은 size의 Input·Button과 높이·좌우 여백·글자 크기가 같습니다. 폭은 Input처럼 감싸는 요소를 채웁니다(`w-full`). 목록은 트리거보다 좁지 않습니다.

<Canvas of={SelectStories.Sizes} />

### 묶음·아이콘·비활성 옵션

`SelectSection`으로 옵션을 묶고 `heading`으로 제목을 붙입니다. 제목은 묶음의 이름이 되고 묶음 앞뒤에 구분선이 그려집니다. 옵션 안에 아이콘(장식용)을 두면 고른 뒤 트리거에도 보입니다. `disabled` 옵션은 흐리게 보이고 고를 수 없으며 키보드 위치가 건너뜁니다. 고른 옵션은 회색 배경과 끝의 체크 아이콘으로 보입니다.

<Canvas of={SelectStories.Sections} />

### 제어

`value`와 `onValueChange(value)`로 고른 값을 앱 상태에 둡니다. `value={null}`이면 아무것도 고르지 않은 상태가 되고 `placeholder`(기본 「선택하세요」)가 보입니다. 비제어로 쓰려면 `defaultValue`를 줍니다. 목록 열림은 `open`/`defaultOpen`/`onOpenChange(open)`로 같은 방식입니다.

<Canvas of={SelectStories.Controlled} />

### 폼 제출과 오류

`name`을 주면 숨은 `<select>`가 함께 그려져 고른 값이 폼에 제출되고, 폼을 reset하면 `defaultValue`로 돌아갑니다. Field의 `required`는 비어 있을 때 제출을 막고 트리거로 포커스를 옮기며 오류 상태로 만듭니다(브라우저 말풍선은 나오지 않으므로 메시지는 Field `error`로 보여 줍니다). Field의 `disabled`는 트리거를 끄고 값을 제출하지 않습니다.

### Don't: 동작을 Select로 고르게 한다

Select는 고른 값이 트리거에 남는 폼 입력입니다. 고르는 순간 실행되는 동작은 Menu로 둡니다.

## 접근성

### 기본 제공

- 역할: 트리거는 `aria-haspopup="listbox"`인 버튼이고 `aria-expanded`, 열렸을 때 `aria-controls`가 붙습니다. 목록은 `listbox`, 옵션은 `option`(`aria-selected`), 묶음은 `group` 역할입니다(React Aria `useSelect`·`useListBox`·`useOption`·`useListBoxSection`).
- 이름: 트리거는 고른 값과 Field label을 함께 읽습니다(예: 「바나나 과일」). 목록의 이름은 label입니다. 설명·오류는 `aria-describedby`로, 오류 상태는 `aria-invalid="true"`로 연결됩니다. label을 누르면 트리거에 포커스가 옵니다.
- 열기: 마우스는 누르는 순간 열립니다. 키보드는 Enter·Space·↓로 열면 고른 옵션(없으면 첫 옵션), ↑로 열면 마지막 옵션에 위치합니다.
- 탐색: ↓↑, Home·End, 영문 글자(그 글자로 시작하는 옵션). 비활성 옵션은 건너뜁니다. 닫힌 트리거에서 글자를 치면 열지 않고 바로 그 옵션을 고릅니다(네이티브 select와 같습니다).
- 고르기: Enter·Space·누름. 고르면 닫히고 포커스가 트리거로 돌아옵니다.
- 닫기: Esc, 바깥 누름, Tab, 그리고 스크린리더용 숨은 닫기 버튼(목록 앞뒤). 열린 동안 바깥은 `inert`라 읽히지도 눌리지도 않고 페이지 스크롤이 잠깁니다.
- 포커스 표시: 트리거는 입력창과 같은 field 표시(경계가 포커스 색, 바깥에 3px halo)이고 클릭으로 포커스해도 보입니다. 오류 상태에서는 포커스 중에 경계와 halo가 오류 색입니다. 목록의 위치는 highlight(primary subtle 배경, primary 글자)이고 고대비 모드에서는 옵션 안쪽 2px 테두리가 시스템 색으로 그려집니다. 고른 옵션은 배경만이 아니라 체크 아이콘으로도 보입니다.
- 쌓임: 목록은 `z-popover`라 Dialog(`z-modal`) 안에서 열어도 위에 보입니다.
- 대비: 값·옵션 글자(`text-default`), placeholder·chevron(`text-muted`), 트리거 경계(`border-strong`)·오류 경계(`border-danger`)·포커스 색은 각 배경과 기준(글자 4.5:1, 경계 3:1) 이상입니다.
- 움직임: 목록은 바로 나타나고 사라질 때만 opacity가 짧게(150ms) 흐려집니다.

### 앱이 할 일

- Field 안에 두거나, Field 없이 쓰면 `aria-label`로 이름을 줍니다.
- 옵션 내용이 글자가 아니면(아이콘만 있으면) `aria-label`을, 타입어헤드 글자가 내용과 다르면 `textValue`를 줍니다.
- `SelectItem`·`SelectSection`은 `Select`(또는 `SelectSection`) 바로 안에 둡니다. Fragment와 배열(`map`)은 되지만, 직접 만든 Component로 옵션을 감싸면 모이지 않습니다. `value`는 목록 안에서 겹치지 않게 줍니다.
- 필수 입력의 오류 메시지는 Field `error`로 보여 줍니다. 필수 여부는 label 뒤의 `*`로만 보이므로 필요하면 설명에도 적습니다.
- 한글 글자로는 타입어헤드가 되지 않습니다(입력기가 조합하는 동안 글자 키가 오지 않습니다). 옵션이 많으면 Combobox를 씁니다.

## Props

모두 client Component입니다. `Select`는 트리거 `<button>`의 props를 받고 `ref`는 그 요소에 연결되며, `className`은 기본 class 뒤에 붙어 충돌하면 이깁니다. `SelectItem`은 옵션 `<div>`의 props를 받습니다. 색·`variant` prop은 없습니다.

| Component       | prop                                                  | 기본값                   |
| --------------- | ----------------------------------------------------- | ------------------------ |
| `Select`        | `value`: `string \| null`(제어, `null`은 비움)        | 없음                     |
| `Select`        | `defaultValue`: `string`(비제어, reset 값)            | 없음(고르지 않음)        |
| `Select`        | `onValueChange`: `(value: string) => void`            | 없음                     |
| `Select`        | `open`·`defaultOpen`·`onOpenChange(open)`             | `defaultOpen` `false`    |
| `Select`        | `name`·`form`·`autoComplete`: 숨은 `<select>`에 붙음  | 없음                     |
| `Select`        | `placeholder`: `string`                               | `"선택하세요"`           |
| `Select`        | `size`: `"sm" \| "md" \| "lg"`                        | `"md"`                   |
| `Select`        | `invalid`·`required`·`disabled`: `boolean`            | Field 값(없으면 `false`) |
| `Select`        | `value`·`onChange`·`type`·`children`은 button 것 제외 |                          |
| `SelectItem`    | `value`: `string`(필수, 제출되는 값)                  |                          |
| `SelectItem`    | `disabled`: `boolean`                                 | `false`                  |
| `SelectItem`    | `textValue`: `string`(타입어헤드 글자)                | 내용의 글자              |
| `SelectItem`    | `role` 제외(option)                                   |                          |
| `SelectSection` | `heading`: `ReactNode`(제목이자 이름)                 | 없음                     |
| `SelectSection` | `aria-label`: `string`(제목이 없을 때)                | 없음                     |
| `SelectSection` | `className`: 묶음 감싸개 class                        | 없음                     |

상태는 `data-open`(트리거와 목록, 열렸을 때), `data-invalid`(트리거, 오류), 네이티브 `:disabled`(트리거), `data-placement`(목록), `data-highlighted`(옵션, 키보드 위치·hover), `data-selected`(옵션, 고른 값), `data-disabled`(옵션, 비활성)로 노출합니다.
