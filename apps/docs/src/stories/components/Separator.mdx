# Separator

내용 묶음 사이를 1px 선으로 나눕니다. 주제가 바뀌는 곳이면 의미 구분, 보기만 나누면 장식용으로 씁니다.

<Canvas of={SeparatorStories.Basic} />

## 사용 시점

- 설정 화면에서 주제가 다른 묶음 사이
- 한 줄 안의 링크나 항목 사이(세로)

## 쓰지 않을 때

- 여백만으로 묶음이 구분되면 선을 넣지 않습니다.
- 목록 항목 사이마다 넣지 않습니다. 목록 구분은 목록의 스타일이 맡습니다.
- 덩어리를 감싸야 하면 Card를 씁니다.

## 예시

### 가로로 나누기

기본은 가로이고 바깥 여백이 없습니다. `className`으로 여백을 줍니다(예: `my-3`).

<Canvas of={SeparatorStories.Horizontal} />

### 세로로 나누기

`orientation="vertical"`은 flex 줄 높이만큼 늘어납니다. 한 줄 안의 항목 사이는 보통 장식이라 `decorative`를 함께 줍니다.

<Canvas of={SeparatorStories.Vertical} />

### 장식으로 두기

`decorative`를 주면 `role="none"`이 붙어 스크린 리더가 선을 읽지 않습니다. 같은 주제가 이어지는데 보기만 나눌 때 씁니다.

<Canvas of={SeparatorStories.Decorative} />

## Do/Don't

### Do: 주제가 바뀌는 곳에 의미 구분을 쓴다

<Canvas of={SeparatorStories.DoTopicChange} />

### Don't: 항목마다 선을 넣는다

스크린 리더가 항목마다 「구분선」을 읽고, 화면도 잘게 쪼개집니다. 목록으로 만들고 여백으로 나눕니다.

<Canvas of={SeparatorStories.DontEveryItem} />

## 접근성

### 기본 제공

- 역할: 네이티브 `<hr>`이라 `separator` 역할(가로)입니다. 세로는 `aria-orientation="vertical"`이 붙습니다. `decorative`면 `role="none"`이라 읽히지 않습니다.
- 포커스: 받지 않습니다.
- 대비: 선(`border-default`)은 장식용 구분선이라 대비 검사 대상이 아닙니다. 구분은 역할과 주변 내용이 전합니다.
- 고대비 모드(forced-colors): 선이 시스템 글자색으로 그려집니다.

### 앱이 할 일

- 의미 구분과 장식을 고릅니다. 주제가 바뀌면 기본값(의미 구분), 아니면 `decorative`입니다.
- 구분의 이름이 필요하면 `aria-label`을 줍니다. 보통은 뒤따르는 제목이 맡습니다.

## Props

서버 컴포넌트로 쓸 수 있습니다. `hr`의 props를 모두 받습니다(`role`은 `decorative`로 고르고, `children`은 없습니다). `ref`는 `hr`에 연결되고, `className`은 기본 class 뒤에 붙어 충돌하면 이깁니다(예: `my-4`, `border-strong`). 루트에는 방향을 나타내는 `data-orientation`이 붙습니다.
