# Tooltip

트리거에 짧은 설명 한 줄을 붙이는 오버레이입니다. 마우스를 올리면 잠깐(기본 0.5초) 뒤에, 키보드로 포커스하면 바로 열립니다. 자주 보는 요소라 움직임 없이 바로 나타나고, 사라질 때만 짧게(150ms) 흐려집니다.

<Canvas of={TooltipStories.Basic} />

## 사용 시점

- 아이콘만 있는 버튼이 무엇을 하는지 덧붙일 때(이름은 `aria-label`, 덧붙이는 설명은 Tooltip)
- 단축키처럼 알면 좋지만 몰라도 되는 정보를 알릴 때

## 쓰지 않을 때

- 꼭 알아야 하는 안내, 오류, 긴 설명은 화면에 직접 씁니다. 터치 기기에서는 마우스를 올릴 수 없어 Tooltip이 보이지 않습니다.
- 버튼·링크 같은 조작 요소를 담아야 하면 Popover를 씁니다. Tooltip에는 포커스가 들어가지 않습니다.
- 입력란의 설명은 Field의 `description`을 씁니다.
- 비활성(`disabled`) 버튼에는 붙이지 않습니다. 비활성 버튼은 포커스·마우스 이벤트를 받지 않아 열리지 않습니다. 왜 쓸 수 없는지는 화면에 씁니다.

## 예시

### 트리거

`TooltipTrigger`는 기본으로 class 없는 `<button>`입니다. Tide 모양을 쓰려면 `render={<IconButton aria-label="…" />}`나 `render={<Button />}`를 줍니다. 열린 동안 트리거의 `aria-describedby`가 설명을 가리킵니다. 트리거에 이미 `aria-describedby`가 있으면 그 뒤에 더합니다.

<Canvas of={TooltipStories.ButtonTrigger} />

### 위치

`placement`로 트리거의 어느 쪽에 띄울지 정합니다. 기본은 `top`(위, 가운데 맞춤)이고 `top start`·`right bottom`처럼 변의 끝에 맞출 수 있습니다. 공간이 모자라면 반대쪽으로 뒤집힙니다. 간격은 `offset`(기본 4px)입니다.

<Canvas of={TooltipStories.Placement} />

### Popover·Dialog 위

Tooltip은 쌓임 단계 `tooltip`(500)이라 Popover(300)·Dialog(200) 위에 그려집니다. Popover가 열린 동안 바깥이 막혀도 Tooltip은 막히지 않습니다. Esc는 Tooltip부터 닫습니다.

<Canvas of={TooltipStories.InPopover} />

### 열리는 시간과 제어

`delay`(기본 500ms)는 마우스를 올린 뒤 열릴 때까지, `closeDelay`(기본 300ms)는 포인터가 떠난 뒤 닫힐 때까지의 시간입니다. 한 Tooltip이 닫힌 뒤 잠깐(0.5초) 안에 다른 트리거로 옮기면 기다리지 않고 바로 열리고, 앞의 것은 흐려지지 않고 바로 사라집니다. `open`/`onOpenChange`로 상태를 제어할 수 있고 `disabled`면 열리지 않습니다.

### Don't: 꼭 필요한 안내를 Tooltip에만 둔다

## 접근성

### 기본 제공

- 역할: 설명은 `tooltip` 역할이고, 열린 동안 트리거의 `aria-describedby`가 설명을 가리켜 스크린리더가 트리거 이름 뒤에 설명을 읽습니다(React Aria `useTooltipTrigger`·`useTooltip`, WAI-ARIA APG Tooltip Pattern).
- 열기: 마우스를 올리면 `delay` 뒤에, 키보드 포커스면 바로 열립니다. 마우스로 눌러 생긴 포커스로는 열리지 않습니다.
- 닫기: Esc, 포커스가 떠남, 트리거 누름, 포인터가 떠남(`closeDelay` 뒤). Esc로 닫아도 포커스는 트리거에 남습니다.
- 포인터를 설명 위로 옮겨도 닫히지 않습니다(WCAG 1.4.13 「hover 가능」). Esc로 언제든 닫을 수 있습니다(「닫기 가능」).
- 포커스: Tooltip은 포커스를 받지 않고 옮기지도 않습니다.
- 쌓임: `z-tooltip`이라 Dialog·Popover 위에 보이고, 그것들이 바깥을 막아도 읽힙니다.
- 대비: 글자(`text-default`)가 raised 표면과 4.5:1 이상입니다. 경계(`border-raised`)는 장식용이라 대비 검사 대상이 아닙니다.
- 고대비 모드(forced-colors): 그림자는 사라지지만 1px 경계가 시스템 글자색으로 그려집니다.
- 움직임 줄이기: 원래 이동·blur가 없어 바뀌는 것이 없습니다. 사라질 때 opacity만 바뀝니다.

### 앱이 할 일

- 아이콘만 있는 트리거에는 `aria-label`로 이름을 줍니다. Tooltip은 이름이 아니라 설명입니다.
- 트리거는 포커스를 받을 수 있는 요소(버튼, 링크)로 둡니다. 그래야 키보드 사용자도 설명을 봅니다.
- 설명은 짧은 글만 담습니다. 조작 요소·꼭 필요한 정보는 넣지 않습니다.

## Props

모두 client Component입니다. `Tooltip`은 DOM 요소가 없고 열림 상태만 갖습니다. `TooltipTrigger`는 `<button>`, `TooltipContent`는 `<div>`의 props를 받고 `ref`는 그 요소에 연결되며, `className`은 기본 class 뒤에 붙어 충돌하면 이깁니다(예: `max-w-80`). 색·`variant`·`size` prop은 없습니다.

| Component        | prop                               | 기본값                         |
| ---------------- | ---------------------------------- | ------------------------------ |
| `Tooltip`        | `open`: `boolean`(제어)            | 없음                           |
| `Tooltip`        | `defaultOpen`: `boolean`(비제어)   | `false`                        |
| `Tooltip`        | `onOpenChange`: `(open) => void`   | 없음                           |
| `Tooltip`        | `delay`: `number`(ms)              | `500`                          |
| `Tooltip`        | `closeDelay`: `number`(ms)         | `300`                          |
| `Tooltip`        | `disabled`: `boolean`              | `false`                        |
| `TooltipTrigger` | `render`: `ReactElement`           | 없음(`<button type="button">`) |
| `TooltipContent` | `placement`: `TooltipPlacement`    | `"top"`                        |
| `TooltipContent` | `offset`: `number`(px)             | `4`                            |
| `TooltipContent` | `role`·`id` 제외(tooltip, 자동 id) |                                |

상태는 `data-open`(설명, 열렸을 때)과 `data-placement`(설명, `top`/`bottom`/`left`/`right`)로 노출합니다.
