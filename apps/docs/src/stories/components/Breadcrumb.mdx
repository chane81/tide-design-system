# Breadcrumb

현재 페이지가 사이트 구조에서 어디에 있는지 상위 페이지 링크로 보여 줍니다. `Breadcrumb`(`<nav>` + `<ol>`), `BreadcrumbItem`(`<li>`), `BreadcrumbLink`(`<a>`), `BreadcrumbCurrent`(현재 페이지)를 조합합니다. 항목 사이 구분자(›)는 Component가 붙입니다.

<Canvas of={BreadcrumbStories.Basic} />

## 사용 시점

- 단계가 셋 이상인 계층 구조(설정 > 조직 > 구성원)에서 상위 단계로 바로 돌아갈 길을 줄 때
- 검색이나 외부 링크로 깊은 페이지에 바로 들어온 사용자에게 위치를 알려 줄 때

## 쓰지 않을 때

- 계층이 한두 단계뿐이면 페이지 제목과 「뒤로」 링크로 충분합니다.
- 방문 기록(지나온 순서)을 보여 주려는 것이면 Breadcrumb이 아닙니다. Breadcrumb은 구조상의 위치입니다.
- 단계를 차례로 진행하는 흐름(가입 1/3단계)은 단계 표시를 씁니다.

## 예시

### 부분

| Component           | 요소                         | 하는 일                                                                        |
| ------------------- | ---------------------------- | ------------------------------------------------------------------------------ |
| `Breadcrumb`        | `<nav>` 안의 `<ol>`          | 이름 있는 탐색 영역. 기본 이름은 「이동 경로」입니다. 좁으면 줄을 바꿉니다.    |
| `BreadcrumbItem`    | `<li>`                       | 앞에 장식용 구분자(16px)를 붙입니다. 첫 항목에서는 숨깁니다.                   |
| `BreadcrumbLink`    | `<a>`                        | 상위 페이지 링크. `text-muted`에 밑줄이 있고 hover에 짙어집니다.               |
| `BreadcrumbCurrent` | `<span aria-current="page">` | 현재 페이지. 링크가 아니고 `text-default`·`label-md`로 링크보다 짙고 굵습니다. |

## Do/Don't

### Do: 페이지 제목 위에 두고 현재 페이지로 끝낸다

경로의 마지막은 지금 보고 있는 페이지(`BreadcrumbCurrent`)입니다. 제목과 같은 이름이면 사용자가 위치를 바로 확인합니다.

<Canvas of={BreadcrumbStories.DoAboveTitle} />

### Don't: 구분자를 직접 넣는다

「/」나 「>」를 글자로 넣으면 스크린리더가 그대로 읽고, Component가 붙이는 구분자와 겹칩니다.

## 접근성

### 기본 제공

- 랜드마크: `<nav>`라 탐색 랜드마크이고 기본 이름 「이동 경로」가 붙습니다(WAI-ARIA APG Breadcrumb Pattern). 항목은 순서 있는 목록(`<ol>`)이라 항목 수와 순서가 읽힙니다.
- 현재 페이지: `BreadcrumbCurrent`에 `aria-current="page"`가 붙습니다. 링크가 아니라 Tab으로 가지 않습니다.
- 구분자: 아이콘 패키지의 `ChevronRightIcon`이고 `aria-hidden`이라 읽히지 않습니다.
- 링크 구분: 링크는 색뿐 아니라 밑줄로도 현재 페이지와 구분됩니다. hover에 글자가 짙어지고 밑줄이 두꺼워집니다.
- 대비: 링크 `text-muted`, 현재 페이지 `text-default`가 표면 층 3개 위에서 4.5:1 이상입니다. 구분자는 장식용이라 대비 검사 대상이 아닙니다.
- 포커스: 링크는 `focus-ring`(3px halo)을 보입니다. 고대비 모드(forced-colors)에서는 halo 대신 outline이 시스템 색으로 그려지고 밑줄·구분자도 남습니다.

### 앱이 할 일

- 한 화면에 Breadcrumb이 둘 이상이거나 다른 탐색 영역과 이름이 겹치면 `aria-label`로 이름을 바꿉니다.
- 마지막 항목은 `BreadcrumbCurrent`로 둡니다. 현재 페이지를 링크로 두려면 `BreadcrumbLink`에 `aria-current="page"`를 직접 줍니다.

## Props

모두 서버 컴포넌트로 쓸 수 있습니다. 부분마다 자기 요소(`nav`, `li`, `a`, `span`)의 props를 받고, `ref`는 그 요소에 연결되며, `className`은 기본 class 뒤에 붙어 충돌하면 이깁니다. `Breadcrumb`의 `ref`·`className`은 `<nav>`에 붙습니다. 색·`variant`·`size` prop은 없습니다.

| Component           | 추가·바뀐 prop                 | 기본값        |
| ------------------- | ------------------------------ | ------------- |
| `Breadcrumb`        | `aria-label`: `string`         | `"이동 경로"` |
| `BreadcrumbLink`    | `render`: `ReactElement`       | 없음(`<a>`)   |
| `BreadcrumbLink`    | `color`(HTML 전역 속성) 제외   |               |
| `BreadcrumbCurrent` | `aria-current`가 항상 `"page"` |               |
| `BreadcrumbItem`    | 없음(요소 props 그대로)        |               |
