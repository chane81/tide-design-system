# Avatar

사용자 이미지를 원 안에 보여 줍니다. 이미지가 없거나 불러오지 못하면 사람 모양 fallback 아이콘이 보입니다. 누르는 동작이 없습니다.

<Canvas of={AvatarStories.Basic} />

## 사용 시점

- 댓글, 작성자, 담당자처럼 사람을 가리킬 때
- 계정 메뉴를 여는 버튼 안에 내 사진을 넣을 때(Button·IconButton 안에 둡니다)

## 쓰지 않을 때

- 사람이 아닌 대상(파일, 앱)의 표시는 아이콘을 씁니다.
- 상태나 분류 라벨은 Badge를 씁니다.
- 눌러서 무언가를 해야 하면 Avatar만 쓰지 않고 Button이나 IconButton 안에 넣습니다.

## 예시

### 이미지가 없거나 불러오지 못할 때

`src`가 없거나 빈 문자열이거나 불러오지 못하면 fallback 아이콘이 보입니다. JavaScript 없이 동작합니다. 아이콘을 아래 층에 그리고 이미지를 그 위 층의 CSS 배경으로 깔아서, 이미지를 받으면 아이콘을 덮고 받지 못하면 아무것도 그리지 않습니다. 그래서 브라우저의 깨진 이미지 표시나 대체 텍스트가 fallback 위에 보이지 않습니다.

<Canvas of={AvatarStories.Fallback} />

### 크기 바꾸기

| `size`     | 크기 | fallback 아이콘 |
| ---------- | ---- | --------------- |
| `xs`       | 24px | 16px            |
| `sm`       | 32px | 20px            |
| `md`(기본) | 40px | 24px            |
| `lg`       | 48px | 28px            |

<Canvas of={AvatarStories.Sizes} />

### fallback 색 고르기

fallback 배경과 아이콘은 색 계열 이름(`gray`, `blue`, `green`, `amber`, `red`, `cyan`와 장식 계열 `purple`, `mint`)으로 고릅니다. 기본값은 `gray`입니다. 뜻이 없는 장식 색이라 Role(`primary`, `danger` 등)은 받지 않습니다. 사람마다 다른 색을 주어 구분을 도울 수 있습니다. 앱이 `ColorFamilyRegistry`에 더한 장식 계열도 받습니다.

<Canvas of={AvatarStories.Colors} />

### 이름 옆에 둘 때

이름이 바로 옆에 적혀 있으면 `alt=""`로 장식용으로 둡니다. 스크린 리더가 같은 이름을 두 번 읽지 않습니다.

<Canvas of={AvatarStories.Decorative} />

## Do/Don't

### Do: 눌러야 하면 Button·IconButton으로 감싼다

버튼이 포커스, 키보드 동작, 이름을 맡습니다. 버튼 이름이 따로 있으면 Avatar는 `alt=""`로 둡니다.

<Canvas of={AvatarStories.DoWrapInButton} />

### Don't: Avatar에 `onClick`만 단다

`span`이라 키보드로 닿지 않고 버튼으로 읽히지 않습니다.

<Canvas of={AvatarStories.DontOnClick} />

## 접근성

### 기본 제공

- 역할: `alt`를 주면 루트가 `role="img"`이고 `alt`가 이름입니다. 이미지가 없어도 같습니다. `alt=""`이면 역할과 이름이 없어 읽히지 않습니다.
- fallback 아이콘과 이미지 층은 숨겨져 따로 읽히지 않습니다.
- 대비: fallback 아이콘과 배경이 4.5:1 이상입니다(색 계열마다 파스텔 글자 × subtle).
- 고대비 모드(forced-colors): 사진은 그대로 그려지고, fallback 아이콘은 시스템 글자색으로 남습니다.

### 앱이 할 일

- `alt`에 사람 이름을 적습니다. 이름이 옆에 이미 있으면 `""`를 줍니다.
- 누르는 동작이 필요하면 Button이나 IconButton 안에 넣습니다.

## Props

서버 컴포넌트로 쓸 수 있습니다. `span`의 props를 받습니다(`color`는 색 계열 이름 `ColorFamilyName`으로 바뀌고, `role`·`aria-label`·`children`은 받지 않습니다). `ref`는 `span`에 연결되고, `className`은 기본 class 뒤에 붙어 충돌하면 이깁니다(예: `rounded-md`). 루트에는 `data-color`가 붙습니다. 이미지는 `<img>`가 아니라 CSS 배경으로 그려서 `srcSet`·`loading`은 받지 않습니다.
