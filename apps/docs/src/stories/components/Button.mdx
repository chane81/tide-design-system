# Button

누르면 저장, 제출, 열기 같은 동작을 바로 실행하는 버튼입니다.

<Canvas of={ButtonStories.Basic} />

## 사용 시점

- 폼 제출, 저장, 대화상자 열기처럼 동작을 실행할 때
- 다른 페이지로 가는 동작을 버튼 모양으로 보여야 할 때(`render`로 링크로 렌더)

## 쓰지 않을 때

- 아이콘만 있으면 IconButton을 씁니다.
- 문장 안에서 다른 페이지로 가면 Link를 씁니다.
- 켜고 끄는 설정이면 Switch를 씁니다.

## 예시

### 채움 방식 고르기

`variant`로 채움 방식을 고릅니다. 기본값은 `solid`입니다.

| `variant` | 모양                           | 쓰는 곳                  |
| --------- | ------------------------------ | ------------------------ |
| `solid`   | 진한 배경, 흰 글자             | 영역의 주요 동작 하나    |
| `subtle`  | 파스텔 배경, 진한 같은 색 글자 | 자주 쓰는 보조 동작      |
| `outline` | 테두리, 색 글자                | 주요 동작 옆의 보조 동작 |
| `ghost`   | 배경 없음, 색 글자             | 툴바, 취소처럼 약한 동작 |

`solid`·`subtle`은 호버·누름에 같은 색이 조금 진해집니다. `outline`·`ghost`는 호버에 같은 색의 가장 연한 파스텔(`faint`), 누름에 한 단계 진한 파스텔(`subtle`)이 깔리고 글자 색은 그대로입니다. `neutral`만 색 없는 호버·누름 배경(`bg-hover`·`bg-active`)을 씁니다.

<Canvas of={ButtonStories.Variants} />

### 색 고르기

`color`로 Role을 고릅니다. 기본값은 `primary`입니다. 바깥 요소의 색은 물려받지 않습니다.

| Role      | 쓰는 곳                                  |
| --------- | ---------------------------------------- |
| `primary` | 화면의 주 동작                           |
| `neutral` | 보조 동작                                |
| `success` | 완료·승인 동작                           |
| `warning` | 주의가 필요한 동작                       |
| `danger`  | 삭제처럼 되돌릴 수 없는 동작             |
| `info`    | 안내 동작                                |
| 앱 Role   | 앱이 더한 Role(예: `brand`). 브랜드 동작 |

<Canvas of={ButtonStories.Colors} />

`blue`, `gray` 같은 색 계열 이름은 받지 않습니다. 색 계열은 뜻이 없는 색이라 Badge·Tag 같은 장식 Component가 씁니다.

앱 Role은 [브랜드 색 더하기](?path=/docs/시작하기-브랜드-색-더하기--docs)로 만든 뒤 `color="brand"`로 씁니다. 대비는 `tide-color`가 검사합니다.

<Canvas of={ButtonStories.Brand} />

### 크기 바꾸기

| `size`     | 높이 | 텍스트 스타일 | 아이콘 |
| ---------- | ---- | ------------- | ------ |
| `xs`       | 24px | `label-sm`    | 14px   |
| `sm`       | 32px | `label-md`    | 14px   |
| `md`(기본) | 40px | `label-md`    | 16px   |
| `lg`       | 48px | `label-lg`    | 20px   |

같은 size의 Input, Select와 한 줄에서 높이가 같습니다. 모서리는 모든 size에서 `rounded-md`(6px)입니다.

`disabled`를 주면 누를 수 없고 커서가 바뀝니다. 링크로 렌더해도 같은 모양으로 막힙니다.

### 링크로 렌더하기

`render`에 요소를 넘기면 그 요소로 렌더합니다. Next.js에서는 `render={<Link href="/settings" />}`처럼 씁니다.

```tsx
// app/page.tsx
import { Button } from "@tide-design/components";
import Link from "next/link";

<Button variant="outline" render={<Link href="/settings" />}>
  설정으로 이동
</Button>;
```

## 접근성

### 기본 제공

- 역할: `button`. 이름은 텍스트입니다. `type` 기본값은 `"button"`이라 폼 안에서 뜻하지 않게 제출하지 않습니다.
- 키보드: Tab으로 포커스하고 Enter, Space로 실행합니다. 링크로 렌더하면 Enter로 실행합니다.
- 포커스 표시: 키보드 포커스에 3px halo가 보입니다. `outline`은 테두리도 포커스 색으로 바뀌고(`focus-field`), 나머지는 halo만 보입니다(`focus-ring`).
- 아이콘: 장식용으로 숨겨 이름에 들어가지 않습니다.
- 로딩: `aria-disabled="true"`가 붙고 이름 뒤에 「로딩 중」이 붙습니다(`loadingLabel`로 바꿉니다). 포커스를 잃지 않습니다.
- 비활성: `button`은 `disabled`, 링크 등은 `aria-disabled="true"`로 알립니다. 링크는 포커스를 받지만 실행되지 않습니다.
- 커서: 누를 수 있으면 손 모양(`pointer`), 로딩 중에는 `wait`, 비활성에는 `not-allowed`입니다. 링크로 렌더해도 같습니다.
- 대비: `subtle` 글자는 기본 상태에서 4.5:1, 호버·누름 배경 위에서 4:1 이상입니다. `outline`·`ghost` 글자는 호버·누름(`faint`·`subtle`) 위에서도 4.5:1 이상이고, 배경이 불투명해 어느 표면에서도 같습니다(`neutral`은 `bg-hover`·`bg-active` 위 4:1 이상). `solid` 위 글자는 4:1 이상입니다([Color](?path=/docs/foundation-컬러--docs) 「대비」).
- 움직임 줄이기: 켜면 누름 축소가 사라집니다. 색 변화는 남습니다.
- 고대비 모드(forced-colors): 모든 채움 방식에 경계가 보입니다.

### 앱이 할 일

- 텍스트로 무엇을 하는지 적습니다(「확인」보다 「저장」).
- 로딩이 끝난 결과(저장됨, 실패)는 처음부터 있던 알림 영역에 텍스트로 넣습니다.
- `subtle` 배경(Alert 등) 안의 `ghost`는 `color`를 바탕과 같은 Role로 주고, `className="text-accent-on-subtle hover:bg-accent-subtle-hover active:bg-accent-subtle-active"`로 글자를 파스텔 글자로 바꿉니다. 그대로 두면 호버 배경(`faint`)이 바탕(`subtle`)보다 연해 눌림이 보이지 않습니다.

## Props

`button`의 props를 모두 받습니다(`color`는 Role로 바뀝니다). `ref`는 루트 요소에 연결되고, `className`은 기본 class 뒤에 붙어 충돌하면 이깁니다(예: `px-8`). 루트에는 `data-color`가 붙습니다. 상태는 `disabled:`, `data-loading`, `data-disabled`(링크로 렌더했을 때)로 덮어씁니다.
