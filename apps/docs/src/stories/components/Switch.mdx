# Switch

알림, 다크 모드처럼 누르는 즉시 켜지고 꺼지는 설정에 쓰는 스위치입니다.

<Canvas of={SwitchStories.Basic} />

## 사용 시점

- 누르자마자 반영되는 설정을 켜고 끌 때
- 설정 화면에서 기능 하나를 켜고 끌 때

## 쓰지 않을 때

- 저장이나 제출 버튼을 눌러야 반영되는 선택은 Checkbox를 씁니다.
- 여러 선택지 중 하나를 고르면 Radio를 씁니다.
- 동작을 한 번 실행하면 Button을 씁니다.

## 예시

### 켜고 끄기

`children`이 label이 됩니다. label 텍스트를 눌러도 켜지고 꺼집니다.

label에 마우스를 올리면 켜진 track은 색이 조금 진해지고, 꺼진 track에는 고른 색의 옅은 배경이 깔립니다(경계는 그대로). 누르면 한 단계 더 진해집니다. Checkbox·Radio와 같은 규칙이고, 비활성일 때는 바뀌지 않습니다.

<Canvas of={SwitchStories.States} />

### 크기 바꾸기

| `size`     | track   | thumb | 텍스트 스타일 |
| ---------- | ------- | ----- | ------------- |
| `sm`       | 28×16px | 10px  | `body-sm`     |
| `md`(기본) | 36×20px | 14px  | `body-md`     |
| `lg`       | 44×24px | 18px  | `body-lg`     |

누르는 영역은 모든 size에서 24×24px 이상입니다.

<Canvas of={SwitchStories.Sizes} />

### 켜진 색 고르기

`color`로 Role(Tide Role 6개와 앱 Role)을 고릅니다. 기본값은 `primary`입니다. 앱 Role은 [브랜드 색 더하기](?path=/docs/시작하기-브랜드-색-더하기--docs)로 만든 뒤 `color="brand"`로 씁니다.

`disabled`는 포커스와 제출에서 빠집니다.

### 설명과 오류 붙이기

Field 안에 두면 Field의 label이 이름이 되고, 설명과 오류가 연결됩니다. 이때 `children`은 비웁니다.

`checked`와 `onChange`를 주면 제어 입력이 됩니다. `defaultChecked`만 주면 브라우저가 상태를 가집니다.

## Do/Don't

### Do: label은 켜진 상태를 말한다

「위치 정보 사용」처럼 켜졌을 때의 뜻을 씁니다. 「켜기/끄기」를 label에 넣지 않습니다.

<Canvas of={SwitchStories.DoStateLabel} />

### Don't: 저장을 눌러야 반영되는 선택에 쓴다

사용자는 스위치가 바로 반영된다고 기대합니다. 제출해야 반영되면 Checkbox를 씁니다.

<Canvas of={SwitchStories.DontNeedsSubmit} />

### Don't: label 없이 둔다

스크린리더가 무엇을 켜는지 알 수 없습니다. `children`, Field, `aria-label` 중 하나로 이름을 줍니다.

<Canvas of={SwitchStories.DontNoLabel} />

## 접근성

### 기본 제공

- 역할: 네이티브 체크박스에 `role="switch"`라 「스위치」로 읽히고, 켜짐 상태도 함께 읽힙니다.
- 키보드: Tab으로 포커스하고 Space로 켜고 끕니다.
- 포커스 표시: 키보드 포커스에 2px 링이 보입니다(`focus-ring`).
- 대비: 꺼진 경계와 thumb, 누르는 동안의 thumb, 켜진 track 위 thumb이 배경과 3:1 이상입니다.
- 고대비 모드(forced-colors): 켜지면 track이 강조 시스템 색으로 채워지고 thumb이 끝으로 갑니다.
- 움직임 줄이기: thumb이 미끄러지지 않고 바로 자리를 바꿉니다. 색 전환은 그대로입니다.

### 앱이 할 일

- 이름을 줍니다(`children`, Field, `aria-label`).
- 바뀐 설정의 결과(저장 실패 등)는 앱의 알림 영역으로 알립니다.

## Props

`input`의 props를 모두 받습니다(`type`, `role`은 바뀌지 않습니다). `ref`와 HTML 속성은 `input`에 연결되고, `className`과 `style`은 바깥 `label`에 붙어 기본 class를 이깁니다(예: `gap-4`). 상태는 `:checked`, `:disabled`, `data-invalid`로 나타나고, 바깥 `label`에는 `data-disabled`, `data-invalid`가 붙습니다.
